3D 좌표계 (X / Y / Z)

Godot의 3D 좌표 규칙

Godot는 Y-up 오른손 좌표계를 사용합니다. Y축이 위, X축이 오른쪽, Z축이 카메라를 향합니다.

축 방향

#        +Y (위)
#         |
#         |
#         +------ +X (오른쪽)
#        /
#       /
#      +Z (카메라 쪽, 앞)

# 오른손 법칙:
# 엄지 = +X (오른쪽)
# 검지 = +Y (위쪽)
# 중지 = +Z (앞쪽)

Vector3 기본값

# Godot 내장 상수
Vector3.UP      # (0, 1, 0)  위
Vector3.DOWN    # (0, -1, 0) 아래
Vector3.RIGHT   # (1, 0, 0)  오른쪽
Vector3.LEFT    # (-1, 0, 0) 왼쪽
Vector3.FORWARD # (0, 0, -1) 앞 (화면 안쪽)
Vector3.BACK    # (0, 0, 1)  뒤 (카메라 쪽)
Vector3.ZERO    # (0, 0, 0)  원점
Vector3.ONE     # (1, 1, 1)
주의: Godot에서 Vector3.FORWARD는 (0, 0, -1)입니다. -Z 방향이 앞쪽입니다. Blender 등 다른 툴과 축이 다를 수 있으니 모델 임포트 시 주의하세요.

Node3D - Transform 기본

기본 노드 3D 공간의 위치, 회전, 크기를 가지는 모든 3D 노드의 부모

extends Node3D

func _ready():
    # 위치 (로컬 좌표)
    position = Vector3(2.0, 1.0, -3.0)  # x, y, z

    # 회전 (라디안)
    rotation = Vector3(0, deg_to_rad(90), 0)  # Y축 90도 회전

    # 회전 (도 단위 - 더 편리!)
    rotation_degrees = Vector3(0, 90, 0)

    # 크기
    scale = Vector3(2.0, 2.0, 2.0)  # 2배 확대

    # 월드 좌표 (절대 좌표)
    global_position = Vector3(5.0, 0, 0)

    # 로컬 이동 (자기 방향 기준)
    translate(Vector3(0, 0, -1))  # 앞으로 1유닛 이동
속성타입좌표 기준설명
positionVector3로컬(부모 기준)위치
global_positionVector3월드(절대)월드 위치
rotationVector3로컬라디안 회전
rotation_degreesVector3로컬도 단위 회전
scaleVector3로컬각 축 크기

카메라 투영 종류

Perspective (원근)

# / 멀수록 작아짐   \

# fov = 90  (넓은 시야, 일반)
# fov = 120 (매우 넓은, 왜곡)

  • 레이싱 게임

Orthogonal (직교)

# |  모든 물체가  |
# |  같은 크기    |
# ----카메라----
#
# size = 5   (줌인)
# size = 10  (기본)
# size = 20  (줌아웃)

# 런타임에 줌 인/아웃
func zoom(amount: float):
    if projection == Camera3D.PROJECTION_PERSPECTIVE:
        fov = clamp(fov - amount, 30.0, 120.0)
    else:
        size = clamp(size - amount, 2.0, 50.0)

Transform3D와 Basis

핵심 개념 위치 + 방향 + 크기를 하나로 표현하는 구조체

# Transform3D 구조
# transform = Transform3D(basis, origin)
#   basis  : Basis (3x3 행렬, 회전+스케일)
#   origin : Vector3 (위치)

func _ready():
    # 현재 트랜스폼 접근
    var t = transform
    print(t.origin)  # 위치
    print(t.basis)   # 회전+스케일

    # Basis의 축 벡터
    var right   = transform.basis.x  # 오른쪽
    var up      = transform.basis.y  # 위쪽
    var forward = -transform.basis.z # 앞쪽
# 자기 방향 기준 이동 (로컬 이동)
func move_forward(delta: float):
    # -Z가 앞 방향이므로
    var forward = -transform.basis.z
    position += forward * speed * delta

# 트랜스폼 보간 (부드러운 전환)
func _process(delta):
    var target_transform = $Target.transform
    transform = transform.interpolate_with(
        target_transform, delta * 5.0
    )

Basis 열 벡터

  • basis.x - 로컬 오른쪽
  • basis.y - 로컬 위쪽
  • basis.z - 로컬 뒤쪽

회전: Euler vs Quaternion

Euler (오일러 각도)

# 직관적 - X,Y,Z 축 회전각
rotation_degrees = Vector3(30, 45, 0)
# X: 고개 숙임 (Pitch)
# Y: 좌우 회전 (Yaw)
# Z: 기울기   (Roll)

# 한 축만 회전
rotation_degrees.y += 90

# 라디안 단위
rotation.y = deg_to_rad(45)

단점: 짐벌 락 (Gimbal Lock) 발생 가능

Quaternion (쿼터니언)

# 4D 벡터 (x, y, z, w)
# 짐벌 락 없음, 부드러운 보간

# 현재 쿼터니언
var q = quaternion

# 축-각도로 쿼터니언 생성
var axis = Vector3.UP
var angle = deg_to_rad(90)
quaternion = Quaternion(axis, angle)

# 부드러운 회전 보간 (slerp)
quaternion = quaternion.slerp(
    target_quat, delta * 5.0
)

언제 무엇을 사용할까?

  • Euler - 간단한 회전, 인스펙터 설정, 단일 축 회전
  • Quaternion - 부드러운 회전 보간, 복잡한 3D 회전, 애니메이션

look_at() - 대상 바라보기

필수 함수 노드를 특정 위치를 향해 회전시킵니다

extends Node3D

@onready var target = $"../Target"

func _process(delta):
    # 대상을 바라보기 (위쪽 = Y축)
    look_at(target.global_position, Vector3.UP)

# look_at 주의사항:
# - 자기 자신의 위치와 같은 좌표를 전달하면 에러!
# - 위쪽 벡터와 바라보는 방향이 평행하면 에러!

즉시 회전

# 바로 대상을 바라봄
func face_target(target_pos: Vector3):
    if global_position != target_pos:
        look_at(target_pos, Vector3.UP)

부드러운 추적

# 서서히 대상을 향해 회전
func smooth_look_at(target_pos: Vector3, delta: float):
    var target_xf = transform.looking_at(
        target_pos, Vector3.UP
    )
    var new_basis = basis.slerp(
        target_xf.basis, delta * 5.0
    )
    basis = new_basis
활용: 카메라 추적, AI 적 시선, 미사일 유도, 빌보드 효과 등 3D 게임에서 필수적으로 사용됩니다.

Vector3 주요 메서드

거리와 방향

# 벡터 길이 (크기)
var v = Vector3(3, 4, 0)
print(v.length())       # 5.0
print(v.length_squared())  # 25 (빠름)

# 정규화 (길이를 1로)
var dir = v.normalized()

# 두 점 사이 거리
var dist = pos_a.distance_to(pos_b)

# 방향 벡터 구하기
var direction = (target - self_pos).normalized()

# 이동
position = position.move_toward(
    target_pos, speed * delta
)

# 보간
position = position.lerp(target_pos, 0.1)

내적과 외적

# 내적 (Dot Product)
# 방향 유사도: 1=같은방향, 0=수직, -1=반대
var dot = forward.dot(to_target)
if dot > 0:
    print("대상이 앞쪽에 있음")

# 외적 (Cross Product)
# 두 벡터에 수직인 벡터 반환
var normal = vec_a.cross(vec_b)

# 각도 (라디안)
var angle = vec_a.angle_to(vec_b)

# 반사 벡터
var reflected = velocity.bounce(wall_normal)

# 벡터 투영
var projected = velocity.project(surface_normal)

# 바닥에 투영 (Y 제거)
var flat = Vector3(v.x, 0, v.z).normalized()

성능 팁

거리 비교 시 distance_to() 대신 distance_squared_to()를 사용하면 제곱근 계산을 생략하여 더 빠릅니다. 비교 기준값도 제곱하면 됩니다.

실습: 간단한 3D 씬 구성

종합 실습 바닥 + 물체 + 카메라 + 조명 구성

# main_3d.gd - 루트 노드 (Node3D)에 연결
extends Node3D

func _ready():
    # 1. 바닥 생성
    var floor = MeshInstance3D.new()
    var plane = PlaneMesh.new()
    plane.size = Vector2(20, 20)
    floor.mesh = plane
    var floor_mat = StandardMaterial3D.new()
    floor_mat.albedo_color = Color(0.3, 0.5, 0.3)
    floor.material_override = floor_mat
    add_child(floor)

    # 2. 상자 생성
    create_box(Vector3(0, 0.5, 0), Color.CORNFLOWER_BLUE)
    create_box(Vector3(3, 0.5, -2), Color.INDIAN_RED)

    # 3. 구 생성
    var sphere_node = MeshInstance3D.new()
    var sphere = SphereMesh.new()
    sphere.radius = 0.5
    sphere.height = 1.0
    sphere_node.mesh = sphere
    sphere_node.position = Vector3(-2, 0.5, 1)
    add_child(sphere_node)

    # 4. 태양광
    var sun = DirectionalLight3D.new()
    sun.rotation_degrees = Vector3(-45, -30, 0)
    sun.shadow_enabled = true
    add_child(sun)

    # 5. 카메라
    var cam = Camera3D.new()
    cam.position = Vector3(0, 5, 8)
    cam.look_at(Vector3.ZERO, Vector3.UP)
    cam.current = true
    add_child(cam)

func create_box(pos: Vector3, color: Color):
    var box_node = MeshInstance3D.new()
    var box = BoxMesh.new()
    box.size = Vector3(1, 1, 1)
    box_node.mesh = box
    box_node.position = pos
    var mat = StandardMaterial3D.new()
    mat.albedo_color = color
    box_node.material_override = mat
    add_child(box_node)

Chapter 13 정리

핵심 요약

  • 좌표계: Y-up 오른손 법칙, -Z가 앞 방향
  • Node3D: position, rotation, scale / Transform3D + Basis
  • MeshInstance3D: 프리미티브 메시(Box, Sphere, Cylinder 등)로 물체 표현
  • Camera3D: Perspective(원근) / Orthogonal(직교) 투영
개념핵심 내용
조명Directional(태양), Omni(전구), Spot(손전등)
머티리얼StandardMaterial3D - albedo, metallic, roughness
회전Euler(직관적) vs Quaternion(보간용), look_at()
Vector3normalized, distance_to, dot, cross, lerp
Basisx=오른쪽, y=위, z=뒤 / -z=앞 방향
환경WorldEnvironment + Sky + 톤매핑 + 안개
