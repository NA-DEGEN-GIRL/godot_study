AudioStreamPlayer 노드 계열

노드 용도 특징
AudioStreamPlayer BGM, UI 효과음 위치 무관, 전역 재생
AudioStreamPlayer2D 2D 게임 효과음 좌우 패닝, 거리 감쇠
AudioStreamPlayer3D 3D 공간 음향 도플러, 감쇠 모델, 방향성
팁: 2D/3D 플레이어는 max_distance 속성으로 소리가 들리는 최대 거리를 설정할 수 있습니다. 기본값이 너무 작으면 소리가 안 들릴 수 있으니 확인하세요.

오디오 리소스: WAV vs OGG

WAV 비압축 포맷

  • 파일 크기가 큼
  • 디코딩 부하 없음
  • 짧은 효과음에 최적
  • 임포트 시 loop 설정 가능

OGG Vorbis 압축 포맷

  • 파일 크기가 작음
  • 스트리밍 재생 가능
  • BGM, 긴 사운드에 최적
  • 임포트 시 loop + loop_offset
주의: WAV 파일은 1분짜리 스테레오 44.1kHz 기준 약 10MB입니다. 효과음은 WAV, 배경음악은 OGG로 분리하는 것이 메모리 관리에 유리합니다.

오디오 재생 제어

extends Node2D

@onready var bgm = $BGMPlayer           # AudioStreamPlayer
@onready var sfx = $SFXPlayer2D         # AudioStreamPlayer2D

func _ready():
    # 스트림 리소스 할당
    bgm.stream = preload("res://audio/bgm_main.ogg")
    sfx.stream = preload("res://audio/sfx_jump.wav")

    # BGM 재생
    bgm.play()

func play_jump_sound():
    sfx.pitch_scale = randf_range(0.9, 1.1)  # 약간의 변화
    sfx.play()

func set_volume(value: float):
    # value: 0.0 ~ 1.0 -> dB 변환
    bgm.volume_db = linear_to_db(value)

func pause_bgm():
    bgm.stream_paused = true

func resume_bgm():
    bgm.stream_paused = false

func stop_all():
    bgm.stop()
    sfx.stop()

핵심 속성 요약

play(from_position) / stop() / volume_db (dB) / pitch_scale (배율) / stream_paused (bool) / playing (읽기 전용)

AudioBus 시스템

버스 구조 예시

# 버스 레이아웃 (하단 패널)
# Master
#   ├── BGM
#   ├── SFX
#   └── Voice

# 플레이어에 버스 지정
$BGMPlayer.bus = "BGM"
$SFXPlayer.bus = "SFX"
$VoicePlayer.bus = "Voice"

코드로 버스 제어

# 버스 인덱스 가져오기
var bgm_idx = AudioServer.get_bus_index("BGM")
var sfx_idx = AudioServer.get_bus_index("SFX")

# 볼륨 설정
AudioServer.set_bus_volume_db(
    bgm_idx, linear_to_db(0.8)
)

# 음소거 토글
AudioServer.set_bus_mute(
    sfx_idx, true
)
팁: 오디오 버스 레이아웃은 프로젝트 하단의 Audio 탭에서 시각적으로 편집할 수 있습니다. default_bus_layout.tres 파일에 저장됩니다.

버스 이펙트 (Reverb / Delay / Compressor)

이펙트 용도 주요 파라미터
Reverb 공간감, 잔향 room_size, damping, wet
Delay 에코, 반복 tap1_delay_ms, tap1_level_db, feedback
Compressor 음량 균일화 threshold, ratio, attack_us
Limiter 클리핑 방지 ceiling_db, threshold_db 
# 코드로 이펙트 제어
var bus_idx = AudioServer.get_bus_index("SFX")
var effect = AudioServer.get_bus_effect(bus_idx, 0)  # 첫 번째 이펙트

if effect is AudioEffectReverb:
    effect.room_size = 0.8
    effect.wet = 0.3

AudioStreamRandomizer

반복 효과음에 자연스러운 변화를 주는 리소스

인스펙터 설정

  • Streams: 오디오 파일 목록 추가
  • Random Pitch: 1.0 +/- 0.1
  • Random Volume: 0 +/- 2 dB
  • Playback Mode: Random (No Repeat)

코드로 설정

var randomizer = AudioStreamRandomizer.new()

# 스트림 추가
randomizer.add_stream(0,
    preload("res://audio/step_01.wav"))
randomizer.add_stream(1,
    preload("res://audio/step_02.wav"))
randomizer.add_stream(2,
    preload("res://audio/step_03.wav"))

# 랜덤 범위 설정
randomizer.random_pitch = 1.1
randomizer.random_volume_offset_db = 2.0

# 플레이어에 할당
$FootstepPlayer.stream = randomizer

활용 사례

발소리, 타격음, 동전 수집 소리, 폭발음 등 반복 빈도가 높은 효과음에 적용하면 자연스러움이 크게 향상됩니다.

GPUParticles2D와 ParticleProcessMaterial

주요 노드 속성

  • emitting: 방출 on/off
  • amount: 파티클 수
  • lifetime: 수명 (초)
  • one_shot: 1회만 방출
  • preprocess: 미리 시뮬레이션
  • texture: 파티클 텍스처

머티리얼 코드 설정

var mat = ParticleProcessMaterial.new()

# 방출 방향 및 퍼짐
mat.direction = Vector3(0, -1, 0)
mat.spread = 30.0

# 중력
mat.gravity = Vector3(0, 98, 0)

# 초기 속도
mat.initial_velocity_min = 100.0
mat.initial_velocity_max = 200.0

# 각속도 (회전)
mat.angular_velocity_min = -90.0
mat.angular_velocity_max = 90.0

# GPUParticles2D에 할당
$GPUParticles2D.process_material = mat
팁: 머티리얼의 속성 대부분은 _min과 _max 쌍으로 존재합니다. 두 값이 다르면 그 범위에서 랜덤 값이 선택되어 자연스러운 변화가 생깁니다.

핵심 3속성: amount, lifetime, emission_shape

amount & lifetime

# 파티클 수
$Particles.amount = 50

# 수명 (초)
$Particles.lifetime = 1.5

# 수명 랜덤화 (머티리얼)
var mat = $Particles.process_material
mat.lifetime_randomness = 0.3
# 0.0 = 모두 동일
# 1.0 = 0~lifetime 완전 랜덤

emission_shape 종류

Shape설명
Point한 점에서 방출
Sphere구 내부에서 방출
SphereSurface구 표면에서만
Box직육면체 내부
Ring원형/링 모양
# Emission shape 코드 설정
var mat = ParticleProcessMaterial.new()
mat.emission_shape = ParticleProcessMaterial.EMISSION_SHAPE_BOX
mat.emission_box_extents = Vector3(200, 10, 0)  # 넓은 영역에서 비처럼 방출

속도, 가속도, 감속

var mat = ParticleProcessMaterial.new()

# 초기 속도
mat.initial_velocity_min = 50.0
mat.initial_velocity_max = 150.0

# 중력 (Vector3 - 2D에서는 x, y만 사용)
mat.gravity = Vector3(0, 98, 0)    # 아래로 중력
# mat.gravity = Vector3(0, -50, 0) # 위로 뜨는 연기

# 선형 가속도 (수명 동안 추가 가속)
mat.linear_accel_min = -10.0
mat.linear_accel_max = 10.0

# 감쇠 (마찰 / 저항)
mat.damping_min = 5.0
mat.damping_max = 15.0      # 점점 느려짐

# 접선 가속도 (회오리 효과)
mat.tangential_accel_min = -20.0
mat.tangential_accel_max = 20.0

# 방사형 가속도 (중심으로/밖으로)
mat.radial_accel_min = -30.0   # 음수: 중심으로
mat.radial_accel_max = 30.0    # 양수: 밖으로

조합 예시

불꽃: 높은 초기 속도 + 강한 중력 + 약한 감쇠 | 연기: 낮은 속도 + 음의 중력(상승) + 강한 감쇠 | 회오리: 접선 가속도 + 방사형 가속도

색상 그라데이션

코드로 Gradient 설정

var mat = ParticleProcessMaterial.new()

# 수명에 따른 색상 변화
var gradient = Gradient.new()
gradient.set_color(0, Color.YELLOW)
gradient.add_point(0.3, Color.ORANGE)
gradient.add_point(0.7, Color.RED)
gradient.set_color(1, Color(1, 0, 0, 0))
# 마지막: 투명하게 사라짐

var tex = GradientTexture1D.new()
tex.gradient = gradient
mat.color_ramp = tex

색상 관련 속성

  • color: 기본 색상 (단색)
  • color_ramp: 수명에 따른 색상 변화
  • color_initial_ramp: 초기 색상 랜덤
  • hue_variation_min/max: 색조 변화 범위
팁: 알파(투명도) 그라데이션만 적용해도 파티클이 자연스럽게 페이드아웃됩니다. Color(1, 1, 1, 0)으로 끝나게 설정하세요.

스케일 커브

var mat = ParticleProcessMaterial.new()

# 기본 스케일 범위
mat.scale_min = 0.5
mat.scale_max = 1.5

# 수명에 따른 스케일 커브
var curve = Curve.new()
curve.add_point(Vector2(0.0, 0.0))   # 시작: 작게
curve.add_point(Vector2(0.2, 1.0))   # 빠르게 커짐
curve.add_point(Vector2(1.0, 0.0))   # 끝: 다시 작게

var curve_tex = CurveTexture.new()
curve_tex.curve = curve
mat.scale_curve = curve_tex

연기 패턴

시작 작게 → 점점 커짐
0.2 → 1.0 → 1.5

불꽃 패턴

시작 크게 → 점점 작아짐
1.0 → 0.5 → 0.0

CPUParticles2D vs GPUParticles2D

항목 GPU CPU
처리 위치 GPU (셰이더) CPU (메인 스레드)
최대 파티클 수 수만 개 수백~수천 개
호환성 OpenGL 3.3+ 모든 환경
커스텀 셰이더 지원 미지원
개별 파티클 접근 불가 가능
웹 빌드 제한적 안정적
변환 팁: GPUParticles2D 노드를 우클릭하면 Convert to CPUParticles2D 메뉴로 간편하게 변환할 수 있습니다. 속성이 자동으로 복사됩니다.

실전: 폭발 이펙트 만들기

extends Node2D

@onready var particles = $GPUParticles2D
@onready var sfx = $AudioStreamPlayer2D

func create_explosion():
    # 파티클 노드 설정
    particles.amount = 64
    particles.lifetime = 0.8
    particles.one_shot = true
    particles.explosiveness = 1.0  # 모두 동시에 방출

    # 머티리얼 설정
    var mat = ParticleProcessMaterial.new()
    mat.emission_shape = ParticleProcessMaterial.EMISSION_SHAPE_SPHERE
    mat.emission_sphere_radius = 5.0
    mat.direction = Vector3(0, 0, 0)
    mat.spread = 180.0              # 전 방향
    mat.initial_velocity_min = 150.0
    mat.initial_velocity_max = 350.0
    mat.gravity = Vector3(0, 200, 0)
    mat.damping_min = 20.0
    mat.damping_max = 40.0

    # 색상 그라데이션: 흰색 -> 주황 -> 빨강 -> 투명
    var grad = Gradient.new()
    grad.set_color(0, Color(1, 1, 0.8))
    grad.add_point(0.2, Color.YELLOW)
    grad.add_point(0.5, Color.ORANGE_RED)
    grad.set_color(1, Color(0.3, 0, 0, 0))
    var grad_tex = GradientTexture1D.new()
    grad_tex.gradient = grad
    mat.color_ramp = grad_tex

    # 스케일: 커졌다 작아짐
    var curve = Curve.new()
    curve.add_point(Vector2(0, 0.5))
    curve.add_point(Vector2(0.15, 1.0))
    curve.add_point(Vector2(1, 0.0))
    var c_tex = CurveTexture.new()
    c_tex.curve = curve
    mat.scale_curve = c_tex
    mat.scale_min = 1.0
    mat.scale_max = 2.5

    particles.process_material = mat
    particles.emitting = true

    # 사운드 동시 재생
    sfx.play()

    # 파티클 끝나면 제거
    await get_tree().create_timer(particles.lifetime + 0.2).timeout
    queue_free()

Chapter 09 정리

오디오

  • Player 전역 / 2D / 3D 선택
  • 리소스 WAV(효과음) / OGG(BGM)
  • 제어 play, stop, volume_db, pitch_scale
  • 버스 그룹별 볼륨/이펙트 관리
  • 랜덤 AudioStreamRandomizer

파티클

  • 노드 GPUParticles2D 기본
  • 머티리얼 ParticleProcessMaterial
  • 모양 emission_shape 설정
  • 동작 속도/가속도/중력/감쇠
  • 외관 색상 그라데이션 + 스케일 커브

핵심 원칙

게임의 느낌(Game Feel)은 시각 + 청각 피드백의 조합으로 완성됩니다. 플레이어의 모든 행동에 적절한 사운드와 파티클을 추가하세요.
