Godot 엔진이란?

  • 오픈소스 크로스 플랫폼 게임 엔진
  • 2014년 첫 공개 (Juan Linietsky & Ariel Manzur)
  • 현재 Godot 4.x - Vulkan 기반 렌더링
  • 2D / 3D 게임 모두 지원
  • 자체 스크립트 언어: GDScript

핵심 철학

“모든 것은 노드(Node)다” - Godot의 핵심 설계 원칙. 모든 게임 요소가 노드 트리로 구성됩니다.

오픈소스 & 완전 무료

MIT 라이선스

상용/비상용 프로젝트 모두 무료. 로열티 없음. 소스코드 수정 가능.

  • 무료 엔진 다운로드 및 사용
  • 무료 상용 게임 출시 - 로열티 0%
  • 무료 소스코드 열람 및 수정
  • 커뮤니티 전 세계 기여자들이 함께 개발
Tip: GitHub에서 godotengine/godot 리포지토리를 확인하면 엔진의 전체 소스코드를 볼 수 있습니다. 이슈와 PR로 직접 기여도 가능합니다!

Godot 4 설치하기

다운로드 방법

  1. godotengine.org 접속
  2. Download Latest 클릭
  3. OS에 맞는 버전 선택
  4. 압축 해제 후 바로 실행!
Tip: Steam에서도 “Godot Engine”을 검색하여 설치할 수 있습니다. 자동 업데이트가 편리합니다.

설치 특징

  • 설치 과정 없음 (포터블)
  • 용량 약 120MB
  • 단일 실행 파일
  • Windows / macOS / Linux

에디터 UI 구성

Godot 에디터 4대 영역

  • 1 뷰포트 - 중앙, 게임 장면 편집
  • 2 씬 독(Scene Dock) - 좌상단, 노드 트리
  • 3 파일시스템 - 좌하단, 프로젝트 파일
  • 4 인스펙터 - 우측, 속성 편집

상단 탭: 2D 3D Script AssetLib

하단 패널: Output Debugger Audio Animation

뷰포트 (Viewport)

2D 뷰포트

  • 마우스 휠: 확대/축소
  • 마우스 중앙 버튼 드래그: 패닝
  • 상단 도구: 이동(W), 회전(E), 크기(S)
  • 스냅 설정으로 정밀 배치

3D 뷰포트

  • 마우스 중앙 버튼: 궤도 회전
  • Shift + 중앙 버튼: 패닝
  • 마우스 휠: 줌
  • 기즈모로 축별 조작
Tip: F5로 전체 프로젝트 실행, F6으로 현재 씬만 실행합니다. F7은 현재 씬을 정지 없이 다시 실행합니다.

파일시스템 (FileSystem)

  • res:// - 프로젝트 루트 경로 (리소스 경로)
  • user:// - 사용자 데이터 경로 (세이브 파일 등)
# 리소스 경로 예시
var texture = load("res://sprites/player.png")
var save_path = "user://save_data.json"

파일시스템 규칙

  • 파일/폴더명은 소문자와 언더스코어 권장
  • .import 폴더는 자동 생성 (건드리지 마세요)
  • 파일 이동/이름변경은 반드시 에디터 내에서 수행

인스펙터 (Inspector)

  • 선택한 노드의 모든 속성 표시
  • 실시간 값 수정 가능
  • 리소스 드래그 앤 드롭
  • 시그널 연결 관리
# @export로 인스펙터에 노출
@export var speed: float = 200.0
@export var health: int = 100
@export var player_name: String = "Hero"
@export var color: Color = Color.WHITE
Tip: @export 어노테이션을 사용하면 코드의 변수를 인스펙터에서 직접 편집할 수 있습니다. 게임 밸런싱에 매우 유용합니다!

노드 시스템 개요

“모든 것은 노드다”

게임의 모든 요소(캐릭터, 카메라, 소리, UI 등)는 노드(Node)로 표현됩니다.

주요 노드 타입

  • Node2D 2D 게임 오브젝트
  • Node3D 3D 게임 오브젝트
  • Control UI 요소
  • Area2D 감지 영역

노드 트리 예시

# 플레이어 노드 트리
CharacterBody2D (Player)
  ├─ Sprite2D
  ├─ CollisionShape2D
  ├─ AnimationPlayer
  └─ Camera2D

씬 시스템 개요

  • 씬(Scene) = 노드 트리를 파일로 저장 (.tscn)
  • 씬 안에 다른 씬을 인스턴스로 포함 가능
  • 재사용성과 모듈화의 핵심
  • 레벨, 캐릭터, UI 등 모두 씬으로 관리
# 씬 인스턴스 생성 (코드)
var bullet_scene = preload(
    "res://scenes/bullet.tscn"
)
var bullet = bullet_scene.instantiate()
add_child(bullet)

합성(Composition) 패턴

Godot은 상속보다 합성을 선호합니다. 작은 씬(컴포넌트)을 조합하여 복잡한 게임 오브젝트를 만듭니다.

권장 프로젝트 구조

res://
├── project.godot          # 프로젝트 설정 파일
├── scenes/                # 씬 파일 (.tscn)
│   ├── player/
│   ├── enemies/
│   └── levels/
├── scripts/               # GDScript 파일 (.gd)
├── sprites/               # 이미지, 스프라이트
├── audio/                 # 사운드, 음악
├── ui/                    # UI 관련 씬/리소스
├── fonts/                 # 폰트 파일
├── shaders/               # 셰이더 파일
└── addons/                # 플러그인
주의: .godot/ 폴더와 .import/ 폴더는 Godot이 자동 생성합니다. 직접 수정하지 마세요. .gitignore에 .godot/을 추가하세요.

project.godot 파일

프로젝트의 핵심 설정 파일 - 이 파일이 있는 폴더가 프로젝트 루트

# project.godot 주요 설정 항목
[application]
config/name="My First Game"
run/main_scene="res://scenes/main.tscn"
config/icon="res://icon.svg"

[display]
window/size/viewport_width=1280
window/size/viewport_height=720

[input]
move_left={ "deadzone": 0.5, "events": [...] }
move_right={ "deadzone": 0.5, "events": [...] }

[rendering]
renderer/rendering_method="forward_plus"
Tip: project.godot는 텍스트 파일이므로 Git으로 버전 관리가 가능합니다. 프로젝트 설정 → 일반 탭에서 GUI로 편집하세요.

첫 프로젝트 만들기

프로젝트 생성 단계

  1. Godot 실행 → 새 프로젝트 클릭
  2. 프로젝트 이름 입력: MyFirstGame
  3. 저장 경로 선택
  4. 렌더러 선택:
    • Forward+ 고품질 3D
    • Mobile 모바일 최적화
    • 호환성 웹/구형 기기 (2D 추천)
  5. 생성 후 편집 클릭!

GDScript 소개

특징

  • Python과 유사한 문법
  • 들여쓰기(Indentation) 기반
  • 동적/정적 타이핑 모두 지원
  • Godot API와 완벽 통합
  • 빠른 개발 속도
# GDScript 기본 구조
extends CharacterBody2D

@export var speed: float = 300.0

func _ready():
    print("게임 시작!")

func _process(delta):
    var input = Input.get_vector(
        "left", "right", "up", "down"
    )
    velocity = input * speed
    move_and_slide()

# 매 프레임마다 실행 (1초에 약 60회)
func _process(delta: float):
    # delta = 이전 프레임과의 시간 간격 (초)
    pass

핵심 콜백 함수

  • _ready() - 노드 초기화 시 1회 호출
  • _process(delta) - 매 프레임 호출 (렌더링 속도)
  • _physics_process(delta) - 물리 프레임마다 호출 (고정 간격)
