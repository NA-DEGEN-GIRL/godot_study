메시(Mesh) 개요

3D 오브젝트의 형태를 정의하는 데이터 구조

메시를 구성하는 핵심 데이터

  • Vertices (정점) - 3D 공간의 점 좌표 (Vector3 배열)
  • Normals (법선) - 각 정점의 방향 벡터 (조명 계산에 사용)
  • UVs (텍스처 좌표) - 2D 텍스처를 3D 표면에 매핑하는 좌표
  • Indices (인덱스) - 정점을 연결하여 삼각형을 구성하는 순서
클래스 용도 특징
Mesh 추상 기본 클래스 직접 사용하지 않음, 공통 인터페이스 제공
ArrayMesh 코드로 정점 데이터 직접 구성 절차적 메시 생성, 최대 유연성
PrimitiveMesh 박스, 구, 실린더 등 기본 도형 파라미터만 설정하면 자동 생성
ImmediateMesh 실시간 디버그 렌더링 매 프레임 다시 그리는 동적 메시
Tip: 대부분의 게임 에셋은 외부 3D 모델링 툴에서 만들어 임포트하지만, 프로토타이핑과 절차적 생성에는 코드 기반 메시가 매우 유용합니다.

프리미티브 메시 종류

PrimitiveMesh 파라미터만으로 빠르게 기본 도형 생성

클래스 형태 주요 파라미터
BoxMesh 직육면체 size (Vector3)
SphereMesh 구 radius, height, rings, segments
CylinderMesh 원기둥 top/bottom_radius, height
CapsuleMesh 캡슐 radius, height
PlaneMesh 평면 size (Vector2)
TorusMesh 토러스(도넛) inner/outer_radius
TextMesh 3D 텍스트 text, font, depth

GDScript로 프리미티브 생성

# 코드로 프리미티브 메시 생성
func create_primitives():
    # 박스 메시
    var box = BoxMesh.new()
    box.size = Vector3(2, 1, 3)

    # 구 메시 (세밀도 조절)
    var sphere = SphereMesh.new()
    sphere.radius = 1.5
    sphere.height = 3.0
    sphere.radial_segments = 32
    sphere.rings = 16

    # 실린더 (원뿔도 가능)
    var cone = CylinderMesh.new()
    cone.top_radius = 0.0   # 꼭대기를 0으로
    cone.bottom_radius = 1.0
    cone.height = 2.0

    # MeshInstance3D에 할당
    var mesh_inst = MeshInstance3D.new()
    mesh_inst.mesh = box
    add_child(mesh_inst)
Tip: radial_segments와 rings를 높이면 더 부드러운 곡면이 만들어지지만 정점 수가 증가하여 성능에 영향을 줍니다. 프로토타입에는 낮은 값, 최종 에셋에는 적절한 값을 사용하세요.

MeshInstance3D 속성

메시를 씬에 배치하고 렌더링하는 핵심 노드

주요 속성

  • mesh - 표시할 Mesh 리소스
  • material_override - 전체 표면 머티리얼 덮어쓰기
  • cast_shadow - 그림자 캐스팅 모드
  • gi_mode - GI(Global Illumination) 참여 방식
  • visibility_range_begin/end - LOD 거리 설정
  • transparency - 투명도 렌더링 순서
주의: cast_shadow를 Off로 설정하면 성능이 향상되지만 시각적 사실감이 떨어집니다. 작은 오브젝트나 카메라에서 먼 오브젝트에 적용하세요. 
# MeshInstance3D 설정 예제
func setup_mesh_instance():
    var mesh_inst = MeshInstance3D.new()
    mesh_inst.mesh = preload("res://assets/models/tree.tres")

    # 그림자 설정
    mesh_inst.cast_shadow = (
        GeometryInstance3D.SHADOW_CASTING_SETTING_ON
    )

    # LOD: 거리별 가시성
    mesh_inst.visibility_range_begin = 0.0
    mesh_inst.visibility_range_end = 50.0
    mesh_inst.visibility_range_fade_mode = (
        GeometryInstance3D.VISIBILITY_RANGE_FADE_SELF
    )

    # 표면별 머티리얼 접근
    var mat = mesh_inst.get_surface_override_material(0)
    if mat == null:
        mat = StandardMaterial3D.new()
        mesh_inst.set_surface_override_material(0, mat)

    # 머티리얼 덮어쓰기 (모든 표면)
    var override_mat = StandardMaterial3D.new()
    override_mat.albedo_color = Color.RED
    mesh_inst.material_override = override_mat

    add_child(mesh_inst)

Normal Map

디테일 폴리곤 없이 표면 울퉁불퉁함 시뮬레이션

Normal Map 원리

  • RGB 값이 법선 방향을 인코딩
  • R = X축, G = Y축, B = Z축 방향
  • 조명 계산 시 실제 요철처럼 반응
  • 실루엣은 변하지 않음 (한계)
Tip: Normal Map의 강도(normal_scale)를 조절하여 효과의 세기를 제어하세요. 1.0이 기본이고, 2.0 이상이면 매우 거친 표면이 됩니다.
주의: Normal Map은 OpenGL 형식과 DirectX 형식이 있습니다. Godot은 OpenGL 형식을 사용합니다. DirectX 형식이면 Green 채널을 반전해야 합니다. 
# Normal Map 적용
func apply_normal_map():
    var mat = StandardMaterial3D.new()
    mat.albedo_texture = preload(
        "res://textures/brick_albedo.png"

    mat.normal_texture = preload(
        "res://textures/brick_normal.png"
    )
    mat.normal_scale = 1.5  # 강도 조절

ShaderMaterial 소개

고급 커스텀 셰이더로 무한한 시각 효과

StandardMaterial3D vs ShaderMaterial

  • StandardMaterial3D - 인스펙터에서 설정, PBR 기반, 간편
  • ShaderMaterial - 코드로 작성, 완전 자유, 고급
# ShaderMaterial 생성 (GDScript)
func create_shader_material():
    var shader_mat = ShaderMaterial.new()
    var shader = Shader.new()
    shader.code = """
    shader_type spatial;

    uniform vec4 color : source_color = vec4(1.0);
    uniform float speed = 2.0;

    void fragment() {
        ALBEDO = color.rgb;
        EMISSION = color.rgb * 0.5;
    }
    """
    shader_mat.shader = shader
    shader_mat.set_shader_parameter("color",
        Color(0.0, 1.0, 0.5))
    return shader_mat

.gdshader 파일 방식 (권장)

# res://shaders/custom.gdshader
# shader_type spatial;
# render_mode blend_mix, cull_back;
#
# uniform vec4 albedo_color : source_color;
# uniform sampler2D albedo_tex;

#
# void fragment() {
#     vec4 tex = texture(albedo_tex, UV);
#     ALBEDO = tex.rgb * albedo_color.rgb;

셰이더 언어 기초

vertex fragment 두 단계의 렌더링 파이프라인

셰이더 파이프라인 흐름

  • vertex() - 정점 위치 변형 (모델 변형, 애니메이션)
  • fragment() - 픽셀 색상 결정 (텍스처, 조명, 효과)
  • light() - 커스텀 조명 모델 (선택 사항)
# 셰이더 기본 구조 (.gdshader 파일)
# shader_type spatial;
# render_mode blend_mix, depth_draw_opaque, cull_back;
#
# // uniform: 외부에서 값 전달 (인스펙터에 노출)
# uniform vec4 base_color : source_color = vec4(1.0, 1.0, 1.0, 1.0);
# uniform float wave_speed = 2.0;
# uniform float wave_height = 0.3;
# uniform sampler2D noise_tex;
#
# // vertex 함수: 정점 위치 변형
# void vertex() {
#     // TIME 내장 변수로 시간 기반 애니메이션
#     float wave = sin(VERTEX.x * 3.0 + TIME * wave_speed) * wave_height;
#     VERTEX.y += wave;
#     // 법선 재계산 (조명이 올바르게 적용되도록)
#     NORMAL = normalize(vec3(-cos(VERTEX.x * 3.0 + TIME * wave_speed) * wave_height * 3.0, 1.0, 0.0));
# }
#
# // fragment 함수: 픽셀 색상 결정
# void fragment() {
#     ALBEDO = base_color.rgb;
#     ROUGHNESS = 0.3;
#     METALLIC = 0.0;
#     // UV 좌표로 텍스처 샘플링
#     vec4 noise = texture(noise_tex, UV + TIME * 0.1);
#     ALBEDO *= noise.rgb;
# }
내장 변수 함수 설명
VERTEX vertex 정점 위치 (로컬 공간)
NORMAL vertex/fragment 법선 벡터
UV vertex/fragment 텍스처 좌표
ALBEDO fragment 기본 색상 출력
EMISSION fragment 발광 색상 출력
TIME 모두 경과 시간 (초)

간단한 셰이더 예제

디졸브 효과

# dissolve.gdshader
# shader_type spatial;
# render_mode cull_disabled;
#
# uniform sampler2D noise_tex;
# uniform float dissolve_amount : hint_range(0.0, 1.0) = 0.0;
# uniform vec4 edge_color : source_color = vec4(1.0, 0.3, 0.0, 1.0);
# uniform float edge_width = 0.05;
#
# void fragment() {
#     float noise = texture(noise_tex, UV).r;
#     // 임계값 이하면 투명 처리
#     if (noise < dissolve_amount) {
#         discard;
#     }
#     // 경계 부근에 발광 색상
#     float edge = smoothstep(dissolve_amount,
#         dissolve_amount + edge_width, noise);
#     ALBEDO = mix(edge_color.rgb,
#         vec3(0.5), edge);
#     EMISSION = (1.0 - edge) * edge_color.rgb * 3.0;
# }
# GDScript에서 디졸브 제어
@onready var mat: ShaderMaterial = (
    $Mesh.material_override
)

func dissolve(duration: float):
    var tween = create_tween()
    tween.tween_method(
        set_dissolve, 0.0, 1.0, duration
    )

func set_dissolve(value: float):
    mat.set_shader_parameter(
        "dissolve_amount", value
    )

CSG (Constructive Solid Geometry)

프로토타이핑 기본 도형의 불리언 연산으로 복잡한 형태 생성

CSG 노드 종류

  • CSGBox3D - 직육면체
  • CSGSphere3D - 구
  • CSGCylinder3D - 원기둥 / 원뿔
  • CSGTorus3D - 토러스
  • CSGPolygon3D - 2D 폴리곤을 돌출/회전
  • CSGMesh3D - 임의 메시를 CSG로 사용
  • CSGCombiner3D - 여러 CSG를 그룹화
주의: CSG는 프로토타이핑 도구입니다. 최종 게임에서는 Mesh > Bake Mesh 로 정적 메시로 변환하여 성능을 확보하세요. 
# CSG 씬 트리 구성 예시
# CSGCombiner3D (루트)
# ├ CSGBox3D (벽)
# │   operation = UNION
# ├ CSGBox3D (문 구멍)
# │   operation = SUBTRACTION
# └ CSGCylinder3D (창문 구멍)

# 코드로 CSG 생성
func create_room():
    var combiner = CSGCombiner3D.new()
    add_child(combiner)

    # 외벽 (큰 박스)
    var outer = CSGBox3D.new()
    outer.size = Vector3(10, 4, 10)
    outer.operation = CSGShape3D.OPERATION_UNION
    combiner.add_child(outer)

    # 내부 공간 (빼기)
    var inner = CSGBox3D.new()
    inner.size = Vector3(9, 3.5, 9)
    inner.position.y = 0.25
    inner.operation = (
        CSGShape3D.OPERATION_SUBTRACTION
    )
    combiner.add_child(inner)

    # 문 (빼기)
    var door = CSGBox3D.new()
    door.size = Vector3(1.2, 2.5, 1)
    door.position = Vector3(0, -0.75, 5)
    door.operation = (
        CSGShape3D.OPERATION_SUBTRACTION
    )
    combiner.add_child(door)

CSG 연산

Union / Intersection / Subtraction 세 가지 불리언 연산

연산 상수 결과 활용 예
Union (합집합) OPERATION_UNION 두 도형을 하나로 합침 벽 조합, 복잡한 형태 구축
Subtraction (차집합) OPERATION_SUBTRACTION 자식 영역을 부모에서 제거 문, 창문, 구멍 뚫기
Intersection (교집합) OPERATION_INTERSECTION 겹치는 영역만 남김 절단면 표현, 클리핑

func create_grass_field():

        MultiMesh.TRANSFORM_3D

    # 각 인스턴스 배치
    for i in mm.instance_count:
        var xform = Transform3D()
        # 랜덤 위치
        var pos = Vector3(
            randf_range(-50, 50),
            0,
            randf_range(-50, 50)
        )

        # 랜덤 회전

            Vector3.UP, randf() * TAU
        )

        var s = randf_range(0.8, 1.5)

        # 랜덤 색상 변화
        var green = randf_range(0.3, 0.8)
        mm.set_instance_color(i,
            Color(0.2, green, 0.1))

    multi.multimesh = mm
    add_child(multi)

# 런타임에 인스턴스 업데이트
func _process(delta: float):
    var mm = $MultiMeshInstance3D.multimesh
    # 바람에 흔들리는 효과
    for i in mm.instance_count:
        var xform = mm.get_instance_transform(i)
        # Y축 회전 미세 조정 (바람)
        var wind = sin(
            Time.get_ticks_msec() * 0.001
            + xform.origin.x * 0.5
        ) * 0.05
        xform.basis = xform.basis.rotated(
            Vector3.RIGHT, wind * delta
        )
        mm.set_instance_transform(i, xform)
Tip: 에디터에서 MultiMeshInstance3D 노드를 선택하면 Populate Surface 도구로 다른 메시 표면 위에 인스턴스를 자동 배치할 수 있습니다.

SurfaceTool

절차적 생성 코드로 정점 단위 메시 구성

# SurfaceTool로 삼각형 생성
func create_triangle() -> ArrayMesh:
    var st = SurfaceTool.new()
    st.begin(Mesh.PRIMITIVE_TRIANGLES)

    # 법선 설정 (앞면)
    st.set_normal(Vector3(0, 0, 1))

    # UV 좌표 + 정점 (순서 중요!)
    st.set_uv(Vector2(0, 1))
    st.add_vertex(Vector3(-1, -1, 0))

    st.set_uv(Vector2(0.5, 0))
    st.add_vertex(Vector3(0, 1, 0))

    st.set_uv(Vector2(1, 1))
    st.add_vertex(Vector3(1, -1, 0))

    return st.commit()
# 절차적 평면 (격자) 생성
func create_grid(
    width: int, depth: int, cell_size: float
) -> ArrayMesh:
    var st = SurfaceTool.new()
    st.begin(Mesh.PRIMITIVE_TRIANGLES)

    for x in width:
        for z in depth:
            var pos = Vector3(
                x * cell_size, 0, z * cell_size
            )
            # 쿼드 (삼각형 2개)
            # 삼각형 1
            st.set_uv(Vector2(0, 0))
            st.add_vertex(pos)
            st.set_uv(Vector2(1, 0))
            st.add_vertex(pos + Vector3(cell_size, 0, 0))
            st.set_uv(Vector2(0, 1))
            st.add_vertex(pos + Vector3(0, 0, cell_size))
            # 삼각형 2
            st.set_uv(Vector2(1, 0))
            st.add_vertex(pos + Vector3(cell_size, 0, 0))
            st.set_uv(Vector2(1, 1))
            st.add_vertex(pos + Vector3(cell_size, 0, cell_size))
            st.set_uv(Vector2(0, 1))
            st.add_vertex(pos + Vector3(0, 0, cell_size))

    # 법선 자동 계산
    st.generate_normals()
    # 접선 자동 계산 (Normal Map용)
    st.generate_tangents()

    return st.commit()
Tip: generate_normals()를 호출하면 정점 법선을 자동 계산합니다. Normal Map을 사용하려면 generate_tangents()도 함께 호출하세요.

UV 매핑 기초 / 챕터 정리

UV 매핑이란?

  • U축 = 가로 (0.0 ~ 1.0)
  • V축 = 세로 (0.0 ~ 1.0)
  • 3D 표면의 각 정점에 2D 텍스처 좌표를 매핑
  • UV가 1을 초과하면 텍스처가 반복(타일링)
