Control 노드 개요

Control = 모든 UI의 기반

Godot의 UI 요소는 모두 Control 클래스를 상속합니다. Node2D와는 별개의 렌더링 체계를 사용하며, 해상도 적응을 위한 앵커/마진 시스템을 내장합니다.

Control 노드 계층 구조

# Control 상속 트리 (일부)
# Control
#   ├── Label          # 텍스트 표시
#   ├── Button         # 클릭 버튼
#   ├── TextureRect    # 이미지 표시
#   ├── Panel          # 배경 패널
#   ├── Container      # 자동 레이아웃
#   │   ├── VBoxContainer
#   │   ├── HBoxContainer
#   │   └── GridContainer
#   ├── LineEdit       # 한 줄 입력
#   ├── TextEdit       # 여러 줄 입력
#   └── Range
#       ├── ProgressBar
#       └── Slider
Tip: 에디터에서 Control 노드를 추가하면 2D 뷰포트에 주황색 점선 사각형으로 표시됩니다. 이 사각형이 Control의 영역(Rect)입니다.

앵커와 마진

앵커(Anchor) 시스템

  • anchor_left / anchor_top - 시작점 비율 (0.0~1.0)
  • anchor_right / anchor_bottom - 끝점 비율
  • offset_* - 앵커 기준 픽셀 오프셋

앵커 프리셋: 에디터 상단의 Layout 메뉴에서 자주 사용하는 앵커 조합을 한 번에 설정할 수 있습니다. 
# 코드로 앵커 설정
func _ready():
    # 전체 화면 채우기
    anchor_left = 0.0
    anchor_top = 0.0
    anchor_right = 1.0
    anchor_bottom = 1.0

    # 또는 프리셋 사용
    set_anchors_preset(
        Control.PRESET_FULL_RECT
    )

    # 하단 중앙 고정
    set_anchors_preset(
        Control.PRESET_CENTER_BOTTOM
    )
프리셋설명사용 예
PRESET_FULL_RECT전체 영역 채움배경, 전체화면 UI
PRESET_CENTER부모 중앙 고정팝업, 타이틀
PRESET_TOP_LEFT좌상단 고정HP 바, 점수
PRESET_BOTTOM_WIDE하단 전체 너비인벤토리 바

컨테이너(Container) 시스템

컨테이너 = 자동 레이아웃

컨테이너에 배치된 자식 Control의 위치와 크기는 컨테이너가 자동으로 관리합니다. 수동으로 위치를 설정해도 컨테이너가 덮어씁니다.

주요 컨테이너

  • VBoxContainer 세로 배치
  • HBoxContainer 가로 배치
  • GridContainer 격자 배치
  • MarginContainer 여백 추가
# 컨테이너 씬 구조 예시
# MarginContainer
#   └── VBoxContainer
#       ├── Label ("제목")
#       ├── HBoxContainer
#       │   ├── Button ("시작")
#       │   └── Button ("설정")
#       └── Label ("버전 정보")

# GridContainer 열 수 설정
@onready var grid = $GridContainer
func _ready():
    grid.columns = 3  # 3열 격자
주의: 컨테이너 안에 있는 자식 노드의 position을 직접 수정하면 매 프레임마다 컨테이너가 덮어쓰므로 의미가 없습니다. 대신 size_flags와 custom_minimum_size를 사용하세요.

RichTextLabel - 서식 텍스트

# RichTextLabel + BBCode
@onready var rtl = $RichTextLabel

func _ready():
    rtl.bbcode_enabled = true
    rtl.text = ""

    # BBCode 문법
    rtl.text = "[b]굵게[/b] [i]기울임[/i]"
    rtl.text += "\n[color=red]빨간색[/color]"
    rtl.text += "\n[font_size=32]큰 글씨[/font_size]"
    rtl.text += "\n[url]클릭 링크[/url]"

    # 타이핑 효과
    rtl.visible_characters = 0

func _process(delta):
    if rtl.visible_characters < len(rtl.text):
        rtl.visible_characters += 1
Tip: RichTextLabel의 visible_characters를 조절하면 RPG 대화창처럼 글자가 한 글자씩 나타나는 타이핑 효과를 쉽게 구현할 수 있습니다.

TextEdit / LineEdit

LineEdit - 한 줄 입력

# LineEdit 사용법
@onready var name_input = $LineEdit

func _ready():
    name_input.placeholder_text = \
        "이름을 입력하세요"
    name_input.max_length = 20

    # 시그널 연결
    name_input.text_submitted.connect(
        _on_name_submitted
    )
    name_input.text_changed.connect(
        _on_text_changed
    )

func _on_name_submitted(text: String):
    print("입력된 이름: ", text)
    name_input.clear()

func _on_text_changed(new_text: String):
    # 실시간 유효성 검사
    if new_text.length() < 2:
        name_input.modulate = Color.RED
    else:
        name_input.modulate = Color.WHITE

TextEdit - 여러 줄 입력

# TextEdit 사용법
@onready var text_area = $TextEdit

func _ready():
    text_area.placeholder_text = \
        "메모를 입력하세요..."

    # 줄바꿈 설정
    text_area.wrap_mode = \
        TextEdit.LINE_WRAPPING_BOUNDARY

    # 읽기 전용 모드
    # text_area.editable = false

    text_area.text_changed.connect(
        _on_text_area_changed

func _on_text_area_changed():
    var char_count = text_area.text.length()
    $CharCount.text = \
        "%d / 500" % char_count

func get_content() -> String:
    return text_area.text.strip_edges()
Tip: LineEdit의 secret 속성을 true로 설정하면 비밀번호 입력 필드처럼 문자가 점으로 표시됩니다. secret_character로 마스킹 문자를 변경할 수도 있습니다.

ProgressBar / TextureProgressBar

ProgressBar

# HP 바 구현
@onready var hp_bar = $ProgressBar

func _ready():
    hp_bar.min_value = 0
    hp_bar.max_value = 100
    hp_bar.value = 100
    hp_bar.show_percentage = false

func take_damage(amount: int):
    hp_bar.value -= amount

    # 색상 변경
    if hp_bar.value < 30:
        hp_bar.modulate = Color.RED
    elif hp_bar.value < 60:
        hp_bar.modulate = Color.YELLOW

func heal(amount: int):
    hp_bar.value = min(
        hp_bar.value + amount,
        hp_bar.max_value
    )

Panel / PanelContainer

Panel vs PanelContainer

  • Panel - 단순 배경 사각형. 자식 배치를 수동으로 관리
  • PanelContainer - 배경 + 자동 레이아웃. 자식이 Panel 영역을 채움

# 씬 구조
# PanelContainer     (배경 + 레이아웃)
#   └── MarginContainer  (여백)
#       └── VBoxContainer
#           ├── Label ("대화 내용")
#           └── Button ("확인")

테마 시스템 (Theme)

Theme = UI 스타일의 중앙 관리

Theme 리소스 하나로 모든 UI 노드의 색상, 폰트, 여백, 배경 스타일을 통합 관리합니다. 부모 노드에 Theme을 설정하면 모든 자식에게 자동 상속됩니다.

Theme 구성 요소

구성 요소설명예시
Color텍스트, 아이콘 색상font_color, font_hover_color
Constant여백, 간격 등 숫자 값margin_left, separation
Font글꼴 리소스font, bold_font
Font Size글꼴 크기font_size
Icon아이콘 텍스처checked, unchecked
StyleBox배경/테두리 스타일normal, hover, pressed
# 코드로 개별 테마 속성 오버라이드
func customize_button(btn: Button):
    # 폰트 색상 변경
    btn.add_theme_color_override("font_color", Color.WHITE)
    btn.add_theme_color_override("font_hover_color", Color.YELLOW)

    # 폰트 크기 변경
    btn.add_theme_font_size_override("font_size", 20)

커스텀 테마 만들기

# 게임 전용 테마 생성
func create_game_theme() -> Theme:
    var theme = Theme.new()

    # 기본 폰트 설정
    var font = load("res://fonts/NotoSansKR-Regular.ttf")
    theme.default_font = font
    theme.default_font_size = 16

    # Button 스타일 설정
    var btn_normal = StyleBoxFlat.new()
    btn_normal.bg_color = Color(0.2, 0.4, 0.7)
    btn_normal.corner_radius_top_left = 6
    btn_normal.corner_radius_top_right = 6
    btn_normal.corner_radius_bottom_left = 6
    btn_normal.corner_radius_bottom_right = 6
    btn_normal.content_margin_left = 16
    btn_normal.content_margin_right = 16
    btn_normal.content_margin_top = 8
    btn_normal.content_margin_bottom = 8
    theme.set_stylebox("normal", "Button", btn_normal)

    var btn_hover = btn_normal.duplicate()
    btn_hover.bg_color = Color(0.3, 0.5, 0.8)
    theme.set_stylebox("hover", "Button", btn_hover)

    var btn_pressed = btn_normal.duplicate()
    btn_pressed.bg_color = Color(0.15, 0.3, 0.55)
    theme.set_stylebox("pressed", "Button", btn_pressed)

    # Button 폰트 색상
    theme.set_color("font_color", "Button", Color.WHITE)
    theme.set_color("font_hover_color", "Button", Color.YELLOW)

    # Panel 스타일
    var panel_style = StyleBoxFlat.new()
    panel_style.bg_color = Color(0.08, 0.08, 0.15, 0.95)
    panel_style.border_color = Color(0.3, 0.5, 0.8, 0.5)
    panel_style.set_border_width_all(1)
    panel_style.set_corner_radius_all(10)
    theme.set_stylebox("panel", "PanelContainer", panel_style)

    return theme
Tip: 에디터에서 Theme 리소스를 만들고 .tres 파일로 저장하면 시각적 편집기에서 실시간 미리보기를 보며 편집할 수 있습니다. 코드보다 에디터 사용을 권장합니다.

size_flags 이해하기

size_flags = 컨테이너 내 공간 분배 규칙

자식 노드가 컨테이너 안에서 어떻게 크기를 차지하고 정렬될지를 결정합니다.

플래그값동작
SIZE_FILL1할당된 영역을 채움 (기본값)
SIZE_SHRINK_BEGIN0최소 크기, 시작점 정렬
SIZE_SHRINK_CENTER4최소 크기, 중앙 정렬
SIZE_SHRINK_END8최소 크기, 끝점 정렬
SIZE_EXPAND2남은 공간까지 확장 시도
SIZE_EXPAND_FILL3EXPAND + FILL 조합
# size_flags 활용 예시
# VBoxContainer 안에서 비율 분배
func setup_layout():
    # 상단 제목: 고정 크기
    $VBox/Title.size_flags_vertical = Control.SIZE_SHRINK_BEGIN

    # 중간 콘텐츠: 남은 공간 모두 차지
    $VBox/Content.size_flags_vertical = Control.SIZE_EXPAND_FILL

    # 하단 버튼: 고정 크기
    $VBox/Buttons.size_flags_vertical = Control.SIZE_SHRINK_END

# HBoxContainer 안에서 비율 분배 (1:2:1)
func setup_columns():
    $HBox/Left.size_flags_horizontal = Control.SIZE_EXPAND_FILL
    $HBox/Left.size_flags_stretch_ratio = 1.0

    $HBox/Center.size_flags_horizontal = Control.SIZE_EXPAND_FILL
    $HBox/Center.size_flags_stretch_ratio = 2.0

    $HBox/Right.size_flags_horizontal = Control.SIZE_EXPAND_FILL
    $HBox/Right.size_flags_stretch_ratio = 1.0

동적 레이아웃 조정

# 화면 크기 변경 감지
func _ready():
    get_tree().root.size_changed.connect(
        _on_viewport_resized
    )
    _on_viewport_resized()

func _on_viewport_resized():
    var size = get_viewport_rect().size

    if size.x < 720:
        # 모바일: 세로 레이아웃
        switch_to_vertical()
    else:
        # 데스크탑: 가로 레이아웃
        switch_to_horizontal()

func switch_to_vertical():
    $HBox.visible = false
    $VBox.visible = true

func switch_to_horizontal():
    $HBox.visible = true
    $VBox.visible = false
주의: get_viewport_rect().size는 프로젝트 설정의 뷰포트 크기가 아닌 실제 윈도우 크기를 반환합니다. Stretch Mode에 따라 값이 달라질 수 있으니 주의하세요.

HUD 만들기

# HUD 씬 구조
# CanvasLayer (layer = 10)
#   └── Control (Full Rect 앵커)
#       ├── MarginContainer (좌상단 - HP)
#       │   └── VBoxContainer
#       │       ├── Label ("HP")
#       │       └── ProgressBar
#       ├── Label (상단 중앙 - 점수)
#       ├── TextureRect (우상단 - 미니맵)
#       └── HBoxContainer (하단 중앙 - 아이템 슬롯)
#           ├── TextureRect (슬롯 1)
#           ├── TextureRect (슬롯 2)
#           └── TextureRect (슬롯 3)
# hud.gd - HUD 관리 스크립트
extends CanvasLayer

@onready var hp_bar = $Control/MarginContainer/VBox/ProgressBar
@onready var score_label = $Control/ScoreLabel
@onready var ammo_label = $Control/AmmoLabel

func update_hp(current: int, max_hp: int):
    hp_bar.max_value = max_hp
    # 부드러운 HP 바 감소
    var tween = create_tween()
    tween.tween_property(hp_bar, "value", current, 0.3)

    # 색상 변경
    if float(current) / max_hp < 0.3:
        hp_bar.modulate = Color(1, 0.3, 0.3)
    else:
        hp_bar.modulate = Color.WHITE

func update_score(score: int):
    score_label.text = "Score: %06d" % score
    # 점수 팝 애니메이션
    var tween = create_tween()
    tween.tween_property(score_label, "scale", Vector2(1.3, 1.3), 0.1)
    tween.tween_property(score_label, "scale", Vector2.ONE, 0.2)

func show_damage_indicator():
    $Control/DamageOverlay.modulate.a = 0.5
    var tween = create_tween()
    tween.tween_property($Control/DamageOverlay, "modulate:a", 0.0, 0.3)

Focus / Tabbing

키보드/게임패드 UI 네비게이션

마우스 없이도 UI를 조작할 수 있도록 포커스 체인을 올바르게 설정하는 것이 중요합니다. 콘솔 게임이나 접근성을 위해 반드시 구현해야 합니다.

# 포커스 이웃 설정 (코드)
func setup_focus_chain():
    var buttons = [
        $VBox/PlayButton,
        $VBox/SettingsButton,
        $VBox/CreditsButton,
        $VBox/QuitButton
    ]

    for i in buttons.size():
        var btn = buttons[i]
        # 위/아래 이웃 설정 (순환)
        var prev_btn = buttons[(i - 1) % buttons.size()]
        var next_btn = buttons[(i + 1) % buttons.size()]
        btn.focus_neighbor_top = prev_btn.get_path()
        btn.focus_neighbor_bottom = next_btn.get_path()

        # 포커스 시각 효과
        btn.focus_entered.connect(_on_focus.bind(btn))
        btn.focus_exited.connect(_on_unfocus.bind(btn))

    # 첫 버튼에 포커스
    buttons[0].grab_focus()

func _on_focus(btn: Button):
    var tw = create_tween()
    tw.tween_property(btn, "scale", Vector2(1.1, 1.1), 0.1)

func _on_unfocus(btn: Button):
    var tw = create_tween()
    tw.tween_property(btn, "scale", Vector2.ONE, 0.1)
Tip: 에디터 인스펙터의 Focus 섹션에서 Neighbor Top/Bottom/Left/Right를 시각적으로 설정할 수 있습니다. Mode를 All로 설정해야 키보드 포커스를 받을 수 있습니다.
