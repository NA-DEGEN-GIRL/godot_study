TileMap 노드 개요

TileMap이란?

격자(Grid) 위에 작은 이미지 조각(타일)을 배치하여 게임 맵을 구성하는 노드입니다. 반복적인 지형을 효율적으로 관리하고, 물리 충돌과 내비게이션까지 타일 단위로 설정할 수 있습니다.

주요 특징

  • 격자 기반 타일 배치
  • 다중 레이어 지원
  • 타일별 물리/내비게이션 설정
  • 자동 타일링 (Terrain)
  • 런타임 타일 수정 가능

노드 구조

# TileMap 핵심 속성
# tile_set: TileSet 리소스
# layers: 타일 레이어 배열
# cell_quadrant_size: 렌더링 최적화 단위

# 기본 타일 크기 (TileSet에서 설정)
# 16x16, 32x32, 64x64 등

TileSet 만들기

생성 단계

  1. TileMap 노드 추가
  2. 인스펙터 → Tile Set → New TileSet
  3. Tile Size 설정 (예: 16x16)
  4. 하단 TileSet 패널 열기
  5. + 버튼 → Atlas 소스 추가
  6. 타일시트 이미지 드래그
  7. 타일 선택 후 속성 편집

아틀라스 소스 설정

자동 타일링: Terrain

Terrain 시스템이란?

인접한 타일의 종류를 분석하여 올바른 모서리, 경계, 내부 타일을 자동으로 선택하는 기능입니다. 맵 디자인 속도가 비약적으로 향상됩니다.

설정 단계

  1. TileSet → Terrain Sets → 새 Terrain Set 추가
  2. Terrain Set Mode 선택: Match Corners and Sides (가장 일반적)
  3. Terrain 추가 (예: Ground, Water, Wall)
  4. TileSet 패널 → Paint 모드 → Terrain 선택
  5. 각 타일의 Peering Bits를 칠하기
  6. TileMap 에디터에서 Terrain 브러시로 그리기
팁: Terrain Mode에는 세 가지가 있습니다. Match Corners and Sides는 47타일, Match Corners는 15타일, Match Sides는 15타일이 필요합니다. 타일시트에 맞는 모드를 선택하세요.

물리 타일: 충돌 설정

Physics Layer 추가

  1. TileSet 인스펙터 → Physics Layers
  2. Add Element로 레이어 추가
  3. Collision Layer / Mask 설정
  4. TileSet 패널 → Paint 모드
  5. Physics Layer 0 선택
  6. 각 타일에 충돌 폴리곤 그리기

충돌 폴리곤 타입

# 타일 충돌은 TileSet 에디터에서

One-way 충돌

플랫포머에서 위로 점프하여 통과하지만 위에서는 착지할 수 있는 플랫폼은 충돌 폴리곤에 One Way 옵션을 활성화하면 됩니다.

타일맵 레이어

extends TileMap

# 레이어 상수 정의
enum TileLayer {
    BACKGROUND = 0,  # 배경 (잔디, 흙)
    TERRAIN = 1,     # 지형 (충돌 있는 벽, 바닥)
    DECORATION = 2,  # 장식 (풀, 꽃, 돌)
    FOREGROUND = 3   # 전경 (플레이어 앞에 표시)
}

func _ready():
    # 레이어별 Z-index 설정 (인스펙터에서도 가능)
    set_layer_z_index(TileLayer.BACKGROUND, -10)
    set_layer_z_index(TileLayer.TERRAIN, 0)
    set_layer_z_index(TileLayer.DECORATION, 5)
    set_layer_z_index(TileLayer.FOREGROUND, 10)

    # 레이어 활성화/비활성화
    set_layer_enabled(TileLayer.FOREGROUND, true)

    # 레이어 투명도
    set_layer_modulate(TileLayer.BACKGROUND, Color(1, 1, 1, 0.7))
팁: TileMap 에디터 상단에서 레이어를 전환하며 편집합니다. 눈 아이콘으로 다른 레이어를 숨기면 현재 레이어 편집에 집중할 수 있습니다.

코드로 타일 배치: set_cell

extends TileMap

const GROUND_SOURCE = 0       # TileSet의 첫 번째 소스
const GROUND_ATLAS = Vector2i(0, 0)  # 아틀라스 내 타일 위치

func place_tile(grid_pos: Vector2i, layer: int = 0):
    # set_cell(layer, coords, source_id, atlas_coords, alternative_tile)
    set_cell(layer, grid_pos, GROUND_SOURCE, GROUND_ATLAS)

func remove_tile(grid_pos: Vector2i, layer: int = 0):
    # source_id를 -1로 설정하면 타일 제거
    set_cell(layer, grid_pos, -1)

func fill_row(y: int, start_x: int, end_x: int):
    for x in range(start_x, end_x + 1):
        place_tile(Vector2i(x, y))

func clear_area(rect: Rect2i, layer: int = 0):
    for x in range(rect.position.x, rect.end.x):
        for y in range(rect.position.y, rect.end.y):
            remove_tile(Vector2i(x, y), layer)

# 월드 좌표 -> 타일 좌표 변환
func world_to_tile(world_pos: Vector2) -> Vector2i:
    return local_to_map(to_local(world_pos))

# 타일 좌표 -> 월드 좌표 변환
func tile_to_world(tile_pos: Vector2i) -> Vector2:
    return to_global(map_to_local(tile_pos))
주의: set_cell의 atlas_coords는 픽셀 좌표가 아니라 아틀라스 내 타일 격자 좌표(Vector2i)입니다. 잘못된 좌표를 넣으면 빈 타일이 됩니다.

코드로 타일 읽기

extends TileMap

func get_tile_info(grid_pos: Vector2i, layer: int = 0):
    # 소스 ID (-1이면 빈 셀)
    var source_id = get_cell_source_id(layer, grid_pos)
    if source_id == -1:
        print("빈 타일")
        return null

    # 아틀라스 좌표
    var atlas_coords = get_cell_atlas_coords(layer, grid_pos)

    # Alternative 타일 ID
    var alt_id = get_cell_alternative_tile(layer, grid_pos)

    return {
        "source": source_id,
        "atlas": atlas_coords,
        "alternative": alt_id
    }

# 커스텀 데이터 활용
func get_tile_speed_modifier(world_pos: Vector2) -> float:
    var tile_pos = local_to_map(to_local(world_pos))
    var data = get_cell_tile_data(0, tile_pos)
    if data:
        # TileSet에서 "speed_modifier" 커스텀 데이터 정의 필요
        return data.get_custom_data("speed_modifier")
    return 1.0  # 기본 속도

# 특정 타일이 있는 셀 모두 찾기
func find_all_tiles(layer: int, source: int, atlas: Vector2i) -> Array:
    var result = []
    var used = get_used_cells(layer)
    for cell in used:
        if get_cell_source_id(layer, cell) == source:
            if get_cell_atlas_coords(layer, cell) == atlas:
                result.append(cell)
    return result

레벨 디자인 팁

디자인 원칙

  • 블록아웃 먼저: 단순 도형으로 구조 확인
  • 난이도 곡선: 쉬움 → 어려움 점진적 상승
  • 랜드마크: 방향 인식을 위한 특징적 요소
  • 안전 공간: 위험 전 휴식 지점 배치
  • 가르치는 레벨: 메커니즘을 안전하게 학습

기술적 팁

  • 모듈식 타일셋 (재사용 극대화)
  • 타일 크기 통일 (16, 32, 64px)
  • 레이어로 깊이감 표현
  • 장식 타일로 단조로움 방지
  • 플레이 테스트 반복

황금 규칙

레벨 디자인은 코딩이 아니라 플레이어 경험의 설계입니다. 항상 플레이어의 시점에서 생각하고, 만들고 테스트하고 수정하는 반복 과정이 핵심입니다.

페이드 전환 (Autoload)

# SceneTransition.gd (싱글톤)
extends CanvasLayer

@onready var anim = $AnimationPlayer

func change_scene(path: String):
    anim.play("fade_out")
    await anim.animation_finished
    get_tree().change_scene_to_file(path)
    anim.play("fade_in")
    await anim.animation_finished

# 사용하는 쪽
func _on_door_entered():
    SceneTransition.change_scene(
        "res://levels/level_02.tscn"
    )
주의: 씬 전환 후 현재 씬의 모든 노드가 해제됩니다. 유지해야 할 데이터는 Autoload 싱글톤에 저장하세요. ColorRect의 알파값을 0에서 1로 애니메이션하면 페이드아웃 효과를 만들 수 있습니다.

레벨 관리 패턴

# LevelManager.gd (Autoload 싱글톤)
extends Node

var level_data = [
    {"path": "res://levels/level_01.tscn", "name": "초원",   "unlocked": true},
    {"path": "res://levels/level_02.tscn", "name": "동굴",   "unlocked": false},
    {"path": "res://levels/level_03.tscn", "name": "성",     "unlocked": false},
    {"path": "res://levels/boss.tscn",     "name": "보스전", "unlocked": false},
]
var current_level_index: int = 0

func get_current_level() -> Dictionary:
    return level_data[current_level_index]

func go_to_level(index: int):
    if index >= 0 and index < level_data.size():
        current_level_index = index
        SceneTransition.change_scene(level_data[index].path)

func next_level():
    var next_idx = current_level_index + 1
    if next_idx < level_data.size():
        level_data[next_idx].unlocked = true
        go_to_level(next_idx)

func restart_level():
    go_to_level(current_level_index)

func get_unlocked_levels() -> Array:
    return level_data.filter(func(l): return l.unlocked)

    var spawn = get_tree() \
        .get_first_node_in_group(
            "player_spawn"

        player.global_position = \
            spawn.global_position

func spawn_enemies():
    var spawns = get_tree() \
        .get_nodes_in_group(
            "enemy_spawns"
        )
    var enemy_scene = preload(
        "res://scenes/enemy.tscn"
    )
    for point in spawns:
        var e = enemy_scene.instantiate()
        e.global_position = \
            point.global_position
        add_child(e)

배경 스크롤: ParallaxBackground

# 씬 구조
# ParallaxBackground
#   ├── Sky (ParallaxLayer)        motion_scale = (0.1, 0.1)
#   │   └── Sprite2D               (하늘 텍스처)
#   ├── Mountains (ParallaxLayer)  motion_scale = (0.3, 0.3)
#   │   └── Sprite2D               (산 텍스처)
#   ├── Trees (ParallaxLayer)      motion_scale = (0.6, 0.5)
#   │   └── Sprite2D               (나무 텍스처)
#   └── Bushes (ParallaxLayer)     motion_scale = (0.9, 0.8)
#       └── Sprite2D               (관목 텍스처)

주요 속성

  • motion_scale: 스크롤 속도 비율
  • motion_offset: 시작 오프셋
  • motion_mirroring: 반복 간격

무한 스크롤

# 이미지 너비만큼 미러링 설정
# 예: 텍스처 너비가 1024px
$Sky.motion_mirroring = Vector2(1024, 0)
$Mountains.motion_mirroring = Vector2(1024, 0)
팁: ParallaxBackground는 카메라가 움직이면 자동으로 레이어를 스크롤합니다. Camera2D가 씬에 있어야 제대로 작동합니다.

카메라 제한 (Camera2D Limit)

extends Camera2D

@export var tilemap: TileMap

func _ready():
    setup_limits()

func setup_limits():
    if not tilemap:
        return

    # TileMap의 사용 영역으로 자동 계산
    var rect = tilemap.get_used_rect()
    var tile_size = tilemap.tile_set.tile_size

    # 좌상단, 우하단 픽셀 좌표
    var map_start = rect.position * tile_size
    var map_end = rect.end * tile_size

    # 카메라 제한 설정
    limit_left = map_start.x
    limit_top = map_start.y
    limit_right = map_end.x
    limit_bottom = map_end.y

    # 스무딩 설정
    position_smoothing_enabled = true
    position_smoothing_speed = 8.0

    # 드래그 마진 (화면 가장자리 근처에서 스크롤 시작)
    drag_horizontal_enabled = true
    drag_vertical_enabled = true
    drag_left_margin = 0.2
    drag_right_margin = 0.2
    drag_top_margin = 0.1
    drag_bottom_margin = 0.3    # 바닥쪽 여유 더 줌

limit_smoothed

limit_smoothed = true로 설정하면 카메라가 제한에 도달할 때 부드럽게 멈춥니다. 급격한 정지 대신 자연스러운 감속 효과를 줍니다.

Chapter 10 정리

타일맵

  • TileMap 격자 기반 맵 구성
  • TileSet 타일 리소스 관리
  • Terrain 자동 타일링

  • Marker2D 스폰 포인트
  • Parallax 배경 스크롤
  • Camera2D 제한과 스무딩

핵심 원칙

좋은 레벨은 기술보다 디자인입니다. 타일맵은 도구일 뿐이고, 중요한 것은 플레이어에게 재미있는 경험을 설계하는 것입니다. 빠르게 만들고, 빠르게 테스트하세요.
