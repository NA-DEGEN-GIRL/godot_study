Resource 클래스 이해

Resource란?

Godot에서 데이터를 저장하고 공유하는 기본 단위입니다.
노드(Node)가 행동을 담당한다면, 리소스(Resource)는 데이터를 담당합니다.

내장 리소스 예시

  • Texture2D 이미지 데이터
  • AudioStream 사운드 데이터
  • PackedScene 씬 파일
  • Shader 셰이더 코드
  • Theme UI 테마

Resource의 특징

  • 파일로 저장 가능 (.tres, .res)
  • 여러 노드에서 공유 가능
  • 에디터 인스펙터에서 편집
  • 참조 카운팅으로 메모리 관리
Tip: .tres는 텍스트 형식(사람이 읽을 수 있음), .res는 바이너리 형식(더 빠르고 작음)입니다.

커스텀 Resource 만들기

class_name으로 전역 등록하면 에디터에서 바로 사용 가능

# item_data.gd - 아이템 데이터 리소스
class_name ItemData
extends Resource

@export var item_name: String = ""
@export var description: String = ""
@export var icon: Texture2D
@export var price: int = 0
@export_enum("Weapon", "Armor", "Potion", "Material") var category: String
@export_range(1, 99) var stack_limit: int = 1
@export var is_consumable: bool = false

# 리소스 내부에도 메서드 정의 가능
func get_display_name() -> String:
    return "[%s] %s" % [category, item_name]

func can_stack() -> bool:
    return stack_limit > 1
Tip: 리소스 파일을 만들려면 에디터에서 새 리소스 > ItemData를 선택하거나, 코드에서 ItemData.new()로 생성합니다.

@export 변수 심화

인스펙터에서 편집 가능한 다양한 속성 타입

# character_stats.gd
class_name CharacterStats
extends Resource

# 기본 타입
@export var character_name: String = "용사"
@export var level: int = 1

# 범위 제한
@export_range(0, 999, 1) var hp: int = 100
@export_range(0.0, 100.0, 0.1) var speed: float = 5.0

# 열거형
@export_enum("전사", "마법사", "궁수", "도적") var job_class: String

# 리소스 참조 (다른 리소스를 포함)
@export var weapon: ItemData
@export var inventory: Array[ItemData] = []

# 그룹화
@export_group("전투 스탯")
@export var attack: int = 10
@export var defense: int = 5
@export var magic: int = 3

@export_group("저항력")
@export_range(0.0, 1.0) var fire_resist: float = 0.0
@export_range(0.0, 1.0) var ice_resist: float = 0.0

# 파일 경로
@export_file("*.png") var portrait_path: String
@export_dir var data_folder: String

    "res://levels/big_level.tscn"

    var scene = ResourceLoader.load_threaded_get(

저장하기 (Save)

# 리소스 생성 후 저장
var new_item = ItemData.new()
new_item.item_name = "불의 검"
new_item.price = 500
new_item.category = "Weapon"

# .tres (텍스트 형식) 저장
ResourceSaver.save(
    new_item,
    "res://data/fire_sword.tres"
)

# .res (바이너리 형식) 저장
ResourceSaver.save(
    new_item,
    "res://data/fire_sword.res"
)
주의: res:// 경로는 내보내기 후 읽기 전용입니다. 사용자 데이터는 반드시 user:// 경로를 사용하세요.

preload vs load

구분 preload() load()
로드 시점 스크립트 로드 시 (컴파일 타임) 코드 실행 시 (런타임)
경로 상수 문자열만 가능 변수 경로 가능
성능 게임 시작 시 한번에 로드 호출 시마다 로드 (캐싱됨)
용도 자주 쓰는 작은 리소스 동적/대용량 리소스 
# preload - 경로가 상수여야 함 (추천: 작은 리소스)
const BULLET_SCENE = preload("res://scenes/bullet.tscn")
const HIT_SOUND = preload("res://audio/hit.wav")
const HERO_STATS = preload("res://data/hero_stats.tres")

func shoot():
    var bullet = BULLET_SCENE.instantiate()
    add_child(bullet)

# load - 동적 경로 가능 (추천: 조건부 로딩)
func load_level(level_num: int):
    var path = "res://levels/level_%d.tscn" % level_num
    var scene = load(path)  # 런타임에 경로 결정
    get_tree().change_scene_to_packed(scene)

# 대용량 리소스: 백그라운드 로딩
func load_world_async(world_name: String):
    var path = "res://worlds/%s.tscn" % world_name
    ResourceLoader.load_threaded_request(path)

# JSON에서 게임 데이터 불러오기
func load_game_json() -> bool:
    if not FileAccess.file_exists("user://savegame.json"):
        print("세이브 파일이 없습니다.")
        return false

    var file = FileAccess.open("user://savegame.json", FileAccess.READ)
    var json_string = file.get_as_text()
    file.close()

    var json = JSON.new()
    var error = json.parse(json_string)
    if error != OK:
        print("JSON 파싱 에러: ", json.get_error_message())
        return false

    var data = json.data
    player_name = data["player"]["name"]
    player_level = data["player"]["level"]
    current_hp = data["player"]["hp"]
    position = Vector2(data["player"]["position"]["x"],
                       data["player"]["position"]["y"])
    return true

세이브 시스템 구현

persist 그룹 패턴으로 여러 노드 데이터를 일괄 저장

# save_manager.gd - 세이브 매니저
extends Node

const SAVE_PATH = "user://savegame.json"

# 저장: persist 그룹의 모든 노드 데이터 수집
func save_game():
    var save_data = []
    var save_nodes = get_tree().get_nodes_in_group("persist")

    for node in save_nodes:
        if not node.has_method("save"):
            continue
        var node_data = node.call("save")
        node_data["_node_path"] = node.get_path()
        node_data["_scene_path"] = node.scene_file_path
        save_data.append(node_data)

    var file = FileAccess.open(SAVE_PATH, FileAccess.WRITE)
    file.store_string(JSON.stringify(save_data, "\t"))
    file.close()
    print("게임 저장 완료!")

# 불러오기: 저장된 노드를 복원
func load_game():
    if not FileAccess.file_exists(SAVE_PATH):
        return false

    # 기존 persist 노드 제거
    for node in get_tree().get_nodes_in_group("persist"):
        node.queue_free()

    var file = FileAccess.open(SAVE_PATH, FileAccess.READ)
    var json = JSON.new()
    json.parse(file.get_as_text())
    file.close()

    for node_data in json.data:
        var scene = load(node_data["_scene_path"])
        var node = scene.instantiate()
        get_node(node_data["_node_path"]).replace_by(node)
        if node.has_method("load_data"):
            node.call("load_data", node_data)
    return true
# player.gd - persist 그룹에 추가된 노드
func save() -> Dictionary:
    return {"hp": hp, "gold": gold, "pos_x": position.x, "pos_y": position.y}

func load_data(data: Dictionary):
    hp = data["hp"]
    gold = data["gold"]
    position = Vector2(data["pos_x"], data["pos_y"])

Autoload (싱글톤) 패턴

Autoload란?

씬 전환과 무관하게 항상 존재하는 전역 노드입니다.
프로젝트 설정 > Autoload 탭에서 등록하면 이름으로 어디서든 접근할 수 있습니다.

Autoload 특징

  • 씬 전환해도 유지됨
  • 전역 이름으로 접근 가능
  • SceneTree 루트 아래에 배치
  • 노드 또는 스크립트 등록 가능
  • 등록 순서대로 초기화

등록 방법

프로젝트 > 프로젝트 설정 > Autoload

이름 경로
GameManager res://autoload/game_manager.gd
AudioManager res://autoload/audio_manager.gd
SaveManager res://autoload/save_manager.gd 
# 어디서든 이름으로 접근
GameManager.add_score(100)
AudioManager.play_sfx("coin")
SaveManager.save_game()

기능별로 Autoload를 분리하여 관리

GameManager

# autoload/game_manager.gd
extends Node

signal score_changed(new_score)
signal game_over

var score: int = 0
var high_score: int = 0
var current_level: int = 1
var is_paused: bool = false

func add_score(amount: int):
    score += amount
    if score > high_score:
        high_score = score
    score_changed.emit(score)

func reset():
    score = 0
    current_level = 1

func pause_game():
    is_paused = !is_paused
    get_tree().paused = is_paused

AudioManager

# autoload/audio_manager.gd
extends Node

var bgm_player: AudioStreamPlayer
var sfx_players: Array[AudioStreamPlayer]
const MAX_SFX = 8

func _ready():
    bgm_player = AudioStreamPlayer.new()
    bgm_player.bus = "BGM"
    add_child(bgm_player)

    for i in MAX_SFX:
        var p = AudioStreamPlayer.new()
        p.bus = "SFX"
        add_child(p)
        sfx_players.append(p)

func play_bgm(stream: AudioStream):
    bgm_player.stream = stream
    bgm_player.play()

func play_sfx(stream: AudioStream):
    for p in sfx_players:
        if not p.playing:
            p.stream = stream
            p.play()
            return

글로벌 게임 상태 관리

시그널 기반 전역 상태 관리 패턴

# autoload/global_state.gd
extends Node

# 시그널 정의
signal health_changed(current, maximum)
signal gold_changed(amount)
signal inventory_updated
signal level_changed(new_level)
signal player_died

# 전역 상태
var player_data: Dictionary = {
    "name": "Player",
    "hp": 100,
    "max_hp": 100,
    "gold": 0,
    "level": 1,
    "exp": 0,
    "exp_next": 100
}

func take_damage(amount: int):
    player_data["hp"] = max(0, player_data["hp"] - amount)
    health_changed.emit(player_data["hp"], player_data["max_hp"])
    if player_data["hp"] <= 0:
        player_died.emit()

func add_gold(amount: int):
    player_data["gold"] += amount
    gold_changed.emit(player_data["gold"])

func gain_exp(amount: int):
    player_data["exp"] += amount
    while player_data["exp"] >= player_data["exp_next"]:
        player_data["exp"] -= player_data["exp_next"]
        player_data["level"] += 1
        player_data["exp_next"] = int(player_data["exp_next"] * 1.5)
        level_changed.emit(player_data["level"])
# hud.gd - 어디서든 시그널 연결
func _ready():
    GlobalState.health_changed.connect(_on_health_changed)
    GlobalState.gold_changed.connect(_on_gold_changed)

func _on_health_changed(current, maximum):
    health_bar.value = float(current) / maximum * 100

설정 관리 (오디오/화면)

# autoload/settings_manager.gd
extends Node

const SETTINGS_PATH = "user://settings.cfg"
var config = ConfigFile.new()

func _ready():
    load_settings()
    apply_all()

func load_settings():
    config.load(SETTINGS_PATH)

func save_settings():
    config.save(SETTINGS_PATH)

# === 오디오 설정 ===
func set_volume(bus_name: String, value: float):
    var bus_idx = AudioServer.get_bus_index(bus_name)
    AudioServer.set_bus_volume_db(bus_idx, linear_to_db(value))
    AudioServer.set_bus_mute(bus_idx, value <= 0.01)
    config.set_value("audio", bus_name + "_vol", value)
    save_settings()

func get_volume(bus_name: String) -> float:
    return config.get_value("audio", bus_name + "_vol", 1.0)

# === 화면 설정 ===
func set_fullscreen(enabled: bool):
    if enabled:
        DisplayServer.window_set_mode(DisplayServer.WINDOW_MODE_FULLSCREEN)
    else:
        DisplayServer.window_set_mode(DisplayServer.WINDOW_MODE_WINDOWED)
    config.set_value("video", "fullscreen", enabled)
    save_settings()

func set_vsync(enabled: bool):
    DisplayServer.window_set_vsync_mode(
        DisplayServer.VSYNC_ENABLED if enabled else DisplayServer.VSYNC_DISABLED
    )
    config.set_value("video", "vsync", enabled)
    save_settings()

# 시작 시 모든 설정 적용
func apply_all():
    set_volume("Master", get_volume("Master"))
    set_volume("BGM", get_volume("BGM"))
    set_volume("SFX", get_volume("SFX"))
    set_fullscreen(config.get_value("video", "fullscreen", false))
    set_vsync(config.get_value("video", "vsync", true))

사용자 데이터 경로 (user://)

res:// vs user://

  • res:// - 프로젝트 리소스 (내보내기 후 읽기 전용)
  • user:// - 사용자 데이터 (읽기/쓰기 가능)
운영체제 user:// 실제 경로
Windows %APPDATA%\Godot\app_userdata\프로젝트명\
macOS ~/Library/Application Support/Godot/app_userdata/프로젝트명/
Linux ~/.local/share/godot/app_userdata/프로젝트명/
Android /data/data/패키지명/files/
Web IndexedDB (브라우저 저장소) 
# 실제 경로 확인
print(OS.get_user_data_dir())

암호화 저장

const SAVE_PASS = "my_secret_key_2024"

# 암호화된 파일 저장
func save_encrypted():
    var data = {
        "hp": 100,
        "gold": 5000,
        "items": ["sword", "shield"]
    }
    var json = JSON.stringify(data)

    var file = FileAccess.open_encrypted_with_pass(
        "user://save.enc",
        FileAccess.WRITE,
        SAVE_PASS
    )
    if file:
        file.store_string(json)
        file.close()
        print("암호화 저장 완료")

복호화 로드

# 암호화된 파일 불러오기
func load_encrypted() -> Dictionary:
    var file = FileAccess.open_encrypted_with_pass(
        "user://save.enc",
        FileAccess.READ,
        SAVE_PASS
    )
    if file == null:
        print("파일 열기 실패")
        return {}

    var json_str = file.get_as_text()
    file.close()

    var json = JSON.new()
    if json.parse(json_str) == OK:
        return json.data
    return {}
주의: 비밀번호가 코드에 하드코딩되면 디컴파일로 노출될 수 있습니다. 완벽한 보안이 아닌 기본적인 변조 방지 용도로 사용하세요. 서버 기반 게임이라면 서버측 검증이 필수입니다.
Tip: FileAccess.open_encrypted에 바이트 키를 직접 전달할 수도 있습니다. 더 강력한 보안이 필요하면 서버 인증이나 해시 검증을 추가하세요.
