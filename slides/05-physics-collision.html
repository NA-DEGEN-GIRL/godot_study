물리 엔진 개요

Godot Physics 2D

Godot 4는 자체 물리 엔진(GodotPhysics2D)을 내장하고 있으며, 중력/마찰/충돌을 자동으로 시뮬레이션합니다.

  • 물리 프레임: 기본 초당 60회 고정 간격으로 실행 (프로젝트 설정에서 변경 가능)
  • 단위: 픽셀 단위 사용 (1미터 = 기본값은 없지만 비율 설정 가능)
  • 기본 중력: 980 px/s² (프로젝트 설정 Physics > 2D에서 변경)
핵심 개념: 물리 바디 노드는 3종류 - StaticBody2D, RigidBody2D, CharacterBody2D. 각각 용도가 다릅니다.
물리 바디움직임주요 용도
StaticBody2D움직이지 않음벽, 바닥, 장애물
RigidBody2D물리 법칙에 따라 자동상자, 공, 파괴물
CharacterBody2D코드로 직접 제어플레이어, NPC

StaticBody2D

고정 물체 물리 세계에서 절대 움직이지 않는 바디

특징

  • 중력/힘의 영향을 받지 않음
  • 다른 바디가 부딪히면 막아줌
  • 성능 비용이 매우 낮음
  • constant_linear_velocity로 컨베이어 벨트 효과 가능

노드 구조

# 씬 트리 구조
StaticBody2D (바닥)
  ├── CollisionShape2D
  └── Sprite2D (선택)
# 컨베이어 벨트 예제
# StaticBody2D 속성에서 설정
# constant_linear_velocity = Vector2(100, 0)
# 위에 올라간 물체가 오른쪽으로 밀림
주의: StaticBody2D를 코드로 position 변경하면 물리 엔진과 충돌이 발생합니다. 움직이는 플랫폼은 AnimatableBody2D를 사용하세요.

RigidBody2D - 주요 속성

물리 시뮬레이션 물리 법칙에 따라 자동으로 움직이는 바디

속성타입기본값설명
massfloat1.0질량 (kg). 클수록 밀리기 어려움
gravity_scalefloat1.0중력 배율. 0이면 무중력
linear_velocityVector2(0,0)현재 이동 속도 (px/s)
angular_velocityfloat0.0회전 속도 (rad/s)
linear_dampfloat0.0이동 감쇠 (공기 저항)
physics_material_overridePhysicsMaterialnull마찰/반발력 재질
# RigidBody2D에 힘 가하기
func _ready():
    # 위쪽으로 발사
    linear_velocity = Vector2(200, -500)

func _on_button_pressed():
    # 순간적인 힘 (impulse)
    apply_impulse(Vector2(0, -300))
    # 지속적인 힘 (force) - _physics_process에서 사용
    apply_force(Vector2(100, 0))

RigidBody2D 모드

freeze + freeze_mode 조합

freezefreeze_mode동작
false-Dynamic: 물리 시뮬레이션
trueSTATICStatic: 고정, 충돌만
trueKINEMATICKinematic: 코드로 이동

사용 예시

  • Dynamic: 떨어지는 상자, 굴러가는 공
  • Static: 잠긴 문, 고정된 블록
  • Kinematic: 움직이는 엘리베이터
# 게임 중 모드 전환 예제
extends RigidBody2D

func freeze_in_place():
    # 물체를 제자리에 고정
    freeze = true
    freeze_mode = RigidBody2D.FREEZE_MODE_STATIC

func release():
    # 다시 물리 시뮬레이션 활성화
    freeze = false

func make_kinematic():
    # 코드로 제어 가능한 모드
    freeze = true
    freeze_mode = RigidBody2D.FREEZE_MODE_KINEMATIC
활용 팁: 퍼즐 게임에서 블록을 집어 올릴 때 Kinematic, 놓을 때 Dynamic으로 전환하면 자연스럽습니다.

Area2D

영역 감지 물리 충돌 없이 겹침(overlap)만 감지하는 노드

주요 용도

  • 아이템 수집 범위
  • 데미지 존 (함정, 용암)
  • 적 감지 범위 (어그로)
  • 씬 전환 트리거
  • 중력/물리 환경 재정의

환경 재정의 속성

# Area2D로 수중 영역 만들기
# 인스펙터에서 설정:
# gravity_space_override = REPLACE
# gravity = 200  (느린 중력)
# linear_damp_space_override = REPLACE
# linear_damp = 5.0  (물 저항)

Area2D vs PhysicsBody2D

Area2D: 통과 가능, 감지만 함 (트리거) / PhysicsBody2D: 통과 불가, 물리 충돌 발생

CollisionShape2D / CollisionPolygon2D

물리 바디의 충돌 영역을 정의하는 필수 자식 노드

CollisionShape2D

  • 미리 정의된 도형 사용
  • shape 속성에 Shape 리소스 할당
  • disabled로 일시 비활성화
  • 성능이 더 좋음 (최적화된 계산)

CollisionPolygon2D

  • 자유로운 다각형 형태
  • 에디터에서 점을 찍어 그리기
  • 복잡한 지형에 적합
  • 볼록(convex) 분해 자동 처리
# 코드로 충돌 형태 생성
func _ready():
    var collision = CollisionShape2D.new()
    var shape = RectangleShape2D.new()
    shape.size = Vector2(64, 64)
    collision.shape = shape
    add_child(collision)

# 충돌 일시 비활성화
func disable_collision():
    $CollisionShape2D.set_deferred("disabled", true)
주의: 충돌 형태를 물리 프로세스 중에 직접 변경하면 오류가 발생합니다. 반드시 set_deferred()를 사용하세요.

Shape 타입들

Shape형태주요 용도성능

CircleShape2D원형공, 코인, 총알가장 빠름
CapsuleShape2D캡슐캐릭터, NPC보통

# 코드로 다양한 Shape 생성
var rect = RectangleShape2D.new()
rect.size = Vector2(100, 50)

var circle = CircleShape2D.new()
circle.radius = 25.0

var capsule = CapsuleShape2D.new()
capsule.radius = 20.0
capsule.height = 60.0
성능 팁: 가능하면 CircleShape2D나 RectangleShape2D처럼 단순한 도형을 사용하세요. 복잡한 폴리곤은 성능에 큰 영향을 줍니다.

충돌 레이어와 마스크

Layer vs Mask

Layer = 내가 존재하는 층 (나는 누구인가) / Mask = 내가 감지하는 층 (누구와 부딪힐까)

레이어 구성 예시

레이어이름대상
1Player플레이어
2Enemy적
3Platform지형
4Item아이템
5Projectile총알/투사체

설정 예시

오브젝트LayerMask
플레이어12, 3, 4
적21, 3, 5
바닥3없음
코인41
프로젝트 설정: Project > Project Settings > Layer Names > 2D Physics에서 각 레이어에 이름을 지정하면 에디터에서 쉽게 관리할 수 있습니다.

레이어/마스크 설정 코드

# 방법 1: 비트 플래그로 직접 설정
# 레이어 1,3에 존재 = 0b00000101 = 5
collision_layer = 5
# 레이어 2,4를 감지 = 0b00001010 = 10
collision_mask = 10
# 방법 2: 함수로 개별 레이어 설정 (추천!)
func _ready():
    # 레이어 1 활성화
    set_collision_layer_value(1, true)
    # 레이어 3도 활성화
    set_collision_layer_value(3, true)

    # 마스크 2번 감지
    set_collision_mask_value(2, true)
    # 마스크 4번도 감지
    set_collision_mask_value(4, true)
# 실전: 무적 상태 토글
func set_invincible(enabled: bool):
    # 무적이면 적 레이어(2) 감지 해제
    set_collision_mask_value(2, not enabled)
    # 투사체 레이어(5) 감지도 해제
    set_collision_mask_value(5, not enabled)
주의: 레이어 번호는 1부터 시작합니다 (0이 아님). set_collision_layer_value(1, true)는 첫 번째 레이어를 활성화합니다.

body_entered / body_exited 시그널

Area2D 물리 바디가 영역에 진입/이탈할 때 발생

# Area2D 스크립트
extends Area2D

func _ready():
    # 시그널 연결
    body_entered.connect(_on_body_entered)
    body_exited.connect(_on_body_exited)

func _on_body_entered(body: Node2D):
    print(body.name, " 영역 진입!")
    if body.is_in_group("player"):
        print("플레이어가 들어왔습니다!")

func _on_body_exited(body: Node2D):
    print(body.name, " 영역 이탈!")

감지 대상

  • body_entered - PhysicsBody2D 감지
  • body_exited - PhysicsBody2D 이탈
  • monitoring = true 필요

이미 겹친 바디 확인

# 현재 영역 안에 있는 바디 목록
var bodies = get_overlapping_bodies()
for body in bodies:
    print(body.name)

area_entered 시그널

Area2D 간 다른 Area2D와의 겹침을 감지

# 히트박스/허트박스 시스템
extends Area2D  # 허트박스 (피격 판정)

func _ready():
    area_entered.connect(_on_area_entered)

func _on_area_entered(area: Area2D):
    # 공격 히트박스가 들어왔는지 확인
    if area.is_in_group("hitbox"):
        var damage = area.get_parent().attack_damage
        take_damage(damage)

func take_damage(amount: int):
    print("피해량: ", amount)

monitoring vs monitorable

monitoring = 이 Area가 다른 것을 감지할 수 있는가 (내가 탐색)
monitorable = 이 Area가 다른 것에 의해 감지될 수 있는가 (남이 탐색)

# 현재 겹쳐 있는 Area2D 목록
var areas = get_overlapping_areas()
for area in areas:
    if area.is_in_group("danger_zone"):
        apply_damage()

RayCast2D

광선 감지 특정 방향으로 광선을 쏘아 첫 번째 충돌 지점을 감지

extends CharacterBody2D

@onready var ray = $RayCast2D

func _physics_process(delta):
    if ray.is_colliding():
        var collider = ray.get_collider()       # 충돌한 객체
        var point = ray.get_collision_point()    # 충돌 지점
        var normal = ray.get_collision_normal()  # 충돌 면의 법선

        if collider.is_in_group("enemy"):
            print("적 발견! 위치: ", point)

주요 속성

  • enabled - 활성화 여부
  • target_position - 방향과 거리
  • collision_mask - 감지할 레이어
  • collide_with_areas - Area 감지
  • collide_with_bodies - Body 감지

활용 예시

  • 바닥 감지 (아래 방향)
  • 벽 감지 (좌우 방향)
  • 적 시야 (AI)
  • 조준선 / 레이저
  • 절벽 감지 (발 앞 아래)
# 방향 전환 시 RayCast도 뒤집기
func flip_direction(facing_right: bool):
    ray.target_position.x = 100 if facing_right else -100

ShapeCast2D

도형 기반 감지 도형을 밀어내며 경로 상의 모든 충돌을 감지

RayCast2D vs ShapeCast2D

구분RayCast2DShapeCast2D
감지 범위가느다란 선도형 크기만큼
결과 수1개여러 개
성능빠름보통
용도시선/조준넓은 범위 감지
# ShapeCast2D 사용 예제
extends Node2D

@onready var cast = $ShapeCast2D

func check_landing_zone():
    cast.force_shapecast_update()

    if cast.is_colliding():
        var count = cast.get_collision_count()
        for i in count:
            var obj = cast.get_collider(i)
            print("감지: ", obj.name)
활용 팁: 캐릭터가 좁은 통로를 지나갈 수 있는지 미리 확인할 때, 캐릭터 크기의 ShapeCast2D를 사용하면 깔끔합니다.

물리 프로세스 vs 일반 프로세스

구분_process(delta)_physics_process(delta)
호출 간격매 렌더 프레임 (가변)고정 간격 (기본 1/60초)
delta 값프레임마다 다름항상 일정 (0.01667...)
용도UI, 비주얼, 입력물리, 이동, 충돌
FPS 영향60fps=60회, 30fps=30회항상 60회 (고정)
extends CharacterBody2D

func _process(delta):
    # UI 업데이트, 애니메이션 (프레임 의존)
    $Sprite2D.rotation += delta * 2.0
    update_health_bar()

func _physics_process(delta):
    # 물리 연산은 반드시 여기서!
    velocity.y += gravity * delta
    velocity.x = input_direction * speed
    move_and_slide()
흔한 실수: move_and_slide()를 _process()에서 호출하면 프레임률에 따라 이동 속도가 달라집니다. 반드시 _physics_process()에서 호출하세요!

One-Way Collision

단방향 충돌 한 방향으로만 충돌, 반대쪽은 통과 가능

사용 사례

  • 플랫포머의 통과 가능한 발판
  • 아래에서 점프하여 올라가기
  • 위에서는 서 있을 수 있음
  • 사다리 상단 플랫폼

설정 방법

# CollisionShape2D 인스펙터에서:
# one_way_collision = true
# one_way_collision_margin = 4.0

# 또는 코드로:
$CollisionShape2D.one_way_collision = true
$CollisionShape2D.one_way_collision_margin = 4.0
# 플랫포머: 아래키로 내려가기
extends CharacterBody2D

func _physics_process(delta):
    if Input.is_action_pressed("move_down"):
        # 현재 서 있는 플랫폼의 충돌 일시 해제
        if is_on_floor():
            var collision = get_last_slide_collision()
            if collision:
                var platform = collision.get_collider()
                if platform.is_in_group("one_way"):
                    position.y += 2  # 살짝 아래로 이동하여 통과

실전: 아이템 수집 예제

종합 예제 Area2D + 충돌 레이어를 활용한 코인 수집

# coin.gd - 코인 아이템 스크립트
extends Area2D

@export var point_value: int = 10
var is_collected := false

func _ready():
    # 레이어 4(Item), 마스크 1(Player)
    set_collision_layer_value(4, true)
    set_collision_mask_value(1, true)
    body_entered.connect(_on_body_entered)

func _on_body_entered(body: Node2D):
    if is_collected:
        return
    if body.is_in_group("player"):
        collect(body)

func collect(player: Node2D):
    is_collected = true
    # 충돌 비활성화 (중복 수집 방지)
    $CollisionShape2D.set_deferred("disabled", true)
    # 점수 추가
    if player.has_method("add_score"):
        player.add_score(point_value)
    # 수집 연출 (Tween)
    var tween = create_tween()
    tween.tween_property(self, "scale", Vector2.ZERO, 0.3)
    tween.tween_property(self, "modulate:a", 0.0, 0.1)
    tween.tween_callback(queue_free)
# player.gd - 플레이어 스크립트 (일부)
extends CharacterBody2D

var score := 0

func _ready():
    add_to_group("player")
    set_collision_layer_value(1, true)

func add_score(points: int):
    score += points
    print("점수: ", score)

Chapter 05 정리

핵심 요약

  • StaticBody2D: 고정 물체 (벽, 바닥)
  • RigidBody2D: 물리 시뮬레이션 물체 (상자, 공)
  • Area2D: 충돌 없이 영역 감지 (트리거)
  • CollisionShape2D: 충돌 형태 정의 (필수)
