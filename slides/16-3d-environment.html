WorldEnvironment 노드

핵심 3D 씬의 전체 환경 효과를 관리

기본 설정

# 씬 트리에 WorldEnvironment 추가
# WorldEnvironment
#   +-- Environment 리소스 할당

# GDScript로 동적 생성
func setup_environment():
    var world_env = WorldEnvironment.new()
    var env = Environment.new()

    # 배경 설정
    env.background_mode = Environment.BG_SKY
    env.ambient_light_source = (
        Environment.AMBIENT_SOURCE_SKY
    )
    env.ambient_light_energy = 0.5

    world_env.environment = env
    add_child(world_env)

Environment 주요 섹션

  • Background - 하늘, 색상, 커스텀 배경
  • Ambient Light - 환경광 소스와 색상
  • Fog - 안개 (일반/볼류메트릭)
  • Tonemap - 색조 매핑 알고리즘
  • SSR - 화면 공간 반사
  • SSAO - 화면 공간 앰비언트 오클루전
  • SSIL - 화면 공간 간접광
  • Glow - 블룸 효과
  • Adjustment - 밝기, 대비, 채도 조정
Tip: Camera3D의 environment 속성이 설정되면 WorldEnvironment보다 우선 적용됩니다. 특정 카메라에만 다른 효과를 줄 때 유용합니다.

Environment 리소스

재사용 가능한 환경 설정 데이터

# Environment 리소스를 코드로 설정
@onready var world_env: WorldEnvironment = $WorldEnvironment

func _ready():
    var env = world_env.environment

    # 배경 모드
    env.background_mode = Environment.BG_SKY
    env.background_energy_multiplier = 1.0

    # 환경광 (그림자 부분의 밝기)
    env.ambient_light_source = Environment.AMBIENT_SOURCE_SKY
    env.ambient_light_color = Color(0.6, 0.7, 0.85)
    env.ambient_light_energy = 0.3

    # 반사 프로브가 없을 때의 기본 반사
    env.reflected_light_source = Environment.REFLECTION_SOURCE_SKY

# 낮/밤 전환 예시
func set_time_of_day(hour: float):
    var env = world_env.environment
    if hour > 6.0 and hour < 18.0:
        # 낮
        env.ambient_light_energy = 0.5
        env.fog_light_color = Color(0.7, 0.75, 0.85)
    else:
        # 밤
        env.ambient_light_energy = 0.05
        env.fog_light_color = Color(0.05, 0.05, 0.15)
주의: Environment 리소스를 여러 WorldEnvironment에서 공유할 경우, 하나를 수정하면 모두 영향받습니다. 독립적인 설정이 필요하면 env.duplicate()로 복제하세요.

하늘 (Sky)

ProceduralSky / PhysicalSky / PanoramaSky

ProceduralSkyMaterial

# 절차적 하늘 - 가볍고 커스텀 용이
func create_procedural_sky():
    var sky_mat = ProceduralSkyMaterial.new()

    # 하늘 색상 (위쪽)
    sky_mat.sky_top_color = Color(
        0.2, 0.4, 0.8)
    sky_mat.sky_horizon_color = Color(
        0.6, 0.7, 0.9)

    # 지면 색상 (아래쪽)
    sky_mat.ground_bottom_color = Color(
        0.1, 0.07, 0.04)
    sky_mat.ground_horizon_color = Color(
        0.6, 0.65, 0.7)

    # 태양 (DirectionalLight3D 연동)
    sky_mat.sun_angle_max = 30.0
    sky_mat.sun_curve = 0.15

    var sky = Sky.new()
    sky.sky_material = sky_mat
    var env = Environment.new()
    env.sky = sky
    env.background_mode = Environment.BG_SKY
    return env

배경 모드 (Background Mode)

모드 상수 설명 용도
Clear Color BG_CLEAR_COLOR 프로젝트 설정의 기본 색상 간단한 테스트
Custom Color BG_COLOR 지정한 단색 배경 스타일라이즈드 게임
Sky BG_SKY Sky 리소스 렌더링 대부분의 3D 게임
Canvas BG_CANVAS 2D 캔버스를 3D 뒤에 2D 배경 + 3D 오브젝트
Keep BG_KEEP 이전 프레임 유지 특수 효과
Camera Feed BG_CAMERA_FEED 실제 카메라 입력 AR 애플리케이션

func set_indoor_background():
    var env = world_env.environment

    env.ambient_light_energy = 0.1

    var env = world_env.environment
    # 야외: 하늘 배경 + 하늘 기반 환경광

안개 (Fog / Volumetric Fog)

일반 Fog (거리 기반)

# 가볍고 기본적인 안개 효과
func setup_fog():
    var env = world_env.environment

    env.fog_enabled = true
    env.fog_light_color = Color(
        0.7, 0.75, 0.85)
    env.fog_light_energy = 1.0

    # 밀도 모드
    env.fog_density = 0.001   # 전체 밀도
    env.fog_aerial_perspective = 0.5

    # 높이 기반 안개 (골짜기에 안개)
    env.fog_height = 0.0       # 안개 높이 기준
    env.fog_height_density = 0.1
Tip: fog_aerial_perspective는 원거리 오브젝트에 안개가 더 강하게 적용되게 합니다. 0.0은 균일, 1.0은 원거리 강조입니다.

Tonemap (톤맵핑)

후처리 HDR을 LDR로 변환하는 알고리즘

func setup_tonemap():
    var env = world_env.environment

    # 톤맵 모드 선택
    env.tonemap_mode = Environment.TONE_MAP_ACES   # 권장
    env.tonemap_exposure = 1.0     # 노출 (밝기 조절)
    env.tonemap_white = 6.0        # 화이트 포인트
모드 상수 특징 권장 용도
Linear TONE_MAP_LINEAR 변환 없음, 밝은 부분 잘림 디버그, 2D 혼합
Reinhard TONE_MAP_REINHARD 부드러운 롤오프, 약간 탈색 밝은 야외 씬
Filmic TONE_MAP_FILMIC S커브, 영화적 느낌, 어두운 톤 시네마틱 게임
ACES TONE_MAP_ACES 영화 표준, 가장 사실적 색감 대부분의 3D 게임 (권장)

tonemap_exposure 활용

  • 0.5 이하 - 어둡고 무거운 분위기 (호러, 던전)
  • 1.0 - 기본값 (일반적인 야외)
  • 1.5 이상 - 밝고 화사한 분위기 (카툰, 판타지)

자동 노출 (Auto Exposure)

장면 밝기에 따라 자동으로 노출 조절

func setup_auto_exposure():
    var env = world_env.environment

    env.auto_exposure_enabled = true

    # 노출 범위
    env.auto_exposure_min_sensitivity = 50.0    # 최소 감도 (밝은 씬)
    env.auto_exposure_max_sensitivity = 800.0   # 최대 감도 (어두운 씬)

    # 적응 속도
    env.auto_exposure_speed = 2.5   # 높을수록 빠르게 적응

    # 기준 밝기 스케일
    env.auto_exposure_scale = 0.4   # 목표 평균 밝기

# 실전 예시: 동굴 입구 연출
# 1. 동굴 내부는 어두움 -> 자동 노출이 감도를 높임
# 2. 동굴 출구에서 밝은 야외로 -> 순간 화이트아웃
# 3. 자동 노출이 감도를 낮춰 정상 밝기로 복원
# -> auto_exposure_speed를 낮추면 적응 시간이 길어져 더 극적

파라미터 가이드

  • min_sensitivity - 밝은 야외에서의 감도
  • max_sensitivity - 어두운 실내에서의 감도
  • speed - 적응 속도 (1.0=느림, 5.0=빠름)
  • scale - 목표 밝기 (낮으면 전체적으로 어두움)
Tip: 자동 노출을 사용할 때는 tonemap_exposure를 1.0으로 유지하세요. 둘 다 조절하면 예측하기 어려운 밝기가 됩니다. 의도한 연출이 아니라면 auto_exposure_speed를 2.0 이상으로 빠르게 설정하는 것이 플레이어에게 편합니다.

글로우 (Glow / Bloom)

후처리 밝은 부분이 빛나는 블룸 효과

func setup_glow():
    var env = world_env.environment

    env.glow_enabled = true

    # 블룸 강도
    env.glow_intensity = 0.8     # 전체 글로우 강도
    env.glow_strength = 1.2      # 글로우 세기
    env.glow_bloom = 0.1         # 전체 화면 블룸 양

    # HDR 임계값 (이 밝기 이상에서만 글로우)
    env.glow_hdr_threshold = 1.0
    env.glow_hdr_scale = 2.0
    env.glow_hdr_luminance_cap = 12.0

    # 블러 레벨 (7단계, 각각 다른 크기의 글로우)
    env.glow_levels_1 = true    # 가장 작은 글로우
    env.glow_levels_2 = false
    env.glow_levels_3 = true    # 중간 글로우
    env.glow_levels_4 = false
    env.glow_levels_5 = true    # 큰 글로우
    env.glow_levels_6 = false
    env.glow_levels_7 = false

    # 블렌드 모드
    env.glow_blend_mode = Environment.GLOW_BLEND_MODE_ADDITIVE  # 가산 합성
    # 다른 옵션: GLOW_BLEND_MODE_SCREEN, GLOW_BLEND_MODE_SOFTLIGHT, GLOW_BLEND_MODE_REPLACE
Tip: glow_hdr_threshold = 1.0이면 표준 밝기 이상에서만 글로우가 발생합니다. 0.0으로 설정하면 모든 밝기에서 글로우가 적용되어 몽환적인 느낌을 줍니다. 네온 머티리얼의 emission_energy를 2.0 이상으로 설정하면 글로우 효과가 잘 드러납니다.

SSAO / SSR

화면 공간 기반 앰비언트 오클루전과 반사

SSAO (앰비언트 오클루전)

func setup_ssao():
    var env = world_env.environment

    env.ssao_enabled = true
    env.ssao_radius = 1.0       # 오클루전 반경
    env.ssao_intensity = 2.0    # 강도
    env.ssao_power = 1.5        # 감쇠 곡선
    env.ssao_detail = 0.5       # 디테일 수준
    env.ssao_horizon = 0.06     # 지평선 각도
    env.ssao_sharpness = 0.98   # 선명도
    env.ssao_light_affect = 0.0 # 직접광 영향

    # SSIL (간접 조명)도 함께 사용하면 효과적
    env.ssil_enabled = true
    env.ssil_radius = 5.0
    env.ssil_intensity = 1.0
Tip: SSAO만으로도 씬의 입체감이 크게 향상됩니다. 성능이 부담되면 radius를 줄이고 intensity를 높여 비슷한 효과를 내세요.

SSR (화면 공간 반사)

func setup_ssr():
    var env = world_env.environment

    env.ssr_enabled = true
    env.ssr_max_steps = 64      # 레이 마칭 스텝 수
    env.ssr_fade_in = 0.15      # 페이드 인 거리
    env.ssr_fade_out = 2.0      # 페이드 아웃 거리
    env.ssr_depth_tolerance = 0.2

    # SSR은 roughness가 낮은
    # 매끄러운 표면에서만 잘 보임

한계: SSR은 화면에 보이지 않는 오브젝트는 반사하지 못합니다. 카메라 밖의 물체나 자기 자신의 뒷면은 반사에 나타나지 않습니다. 완벽한 반사가 필요하면 ReflectionProbe를 함께 사용하세요.

DirectionalLight3D 상세

필수 태양/달 - 평행광원

# DirectionalLight3D 코드 설정
func setup_sun():
    var sun = DirectionalLight3D.new()
    sun.light_color = Color(1.0, 0.95, 0.85)   # 약간 따뜻한 태양
    sun.light_energy = 1.0                       # 밝기
    sun.light_angular_distance = 1.0             # 태양 크기 (소프트 섀도)

    # 그림자 설정
    sun.shadow_enabled = true
    sun.shadow_bias = 0.05
    sun.shadow_normal_bias = 1.0

    # 그림자 캐스케이드 (거리별 그림자 품질)
    sun.directional_shadow_mode = DirectionalLight3D.SHADOW_PARALLEL_4_SPLITS
    sun.directional_shadow_max_distance = 100.0       # 최대 그림자 거리
    sun.directional_shadow_split_1 = 0.1              # 1단계 분할 비율
    sun.directional_shadow_split_2 = 0.2              # 2단계 분할 비율
    sun.directional_shadow_split_3 = 0.5              # 3단계 분할 비율

    # 회전으로 태양 방향 설정 (X축: 고도, Y축: 방위)
    sun.rotation_degrees = Vector3(-45, 30, 0)

    add_child(sun)

그림자 캐스케이드 (Split)

  • SHADOW_PARALLEL_2_SPLITS - 2단계 분할 (가볍지만 저품질)
  • SHADOW_PARALLEL_4_SPLITS - 4단계 분할 (권장, 균형 잡힌 품질)
  • 가까운 거리에 높은 해상도, 먼 거리에 낮은 해상도로 분배
  • split 비율을 작게 하면 가까운 곳의 그림자가 더 선명해짐

OmniLight3D 상세

점광원 모든 방향으로 퍼지는 빛

# 횃불 조명 예시
func create_torch_light() -> OmniLight3D:
    var light = OmniLight3D.new()
    light.light_color = Color(1.0, 0.7, 0.3)
    light.light_energy = 2.0
    light.omni_range = 8.0
    light.omni_attenuation = 1.5

    # 그림자
    light.shadow_enabled = true
    light.shadow_bias = 0.1

    # 그림자 모드
    light.omni_shadow_mode = (
        OmniLight3D.SHADOW_DUAL_PARABOLOID
    )
    # SHADOW_DUAL_PARABOLOID: 빠름
    # SHADOW_CUBE: 고품질

    return light

# 횃불 깜빡임 효과
func _process(delta: float):
    var flicker = 1.0 + sin(
        Time.get_ticks_msec() * 0.01
    ) * 0.15
    flicker += randf_range(-0.05, 0.05)
    torch_light.light_energy = 2.0 * flicker

감쇠 곡선 (Attenuation)

값 감쇠 유형 느낌
0.5 매우 느린 감쇠 넓게 퍼지는 부드러운 빛
1.0 선형 감쇠 자연스러운 기본값
2.0 물리 기반 역제곱 사실적이지만 급격
4.0 매우 빠른 감쇠 좁은 범위 집중

성능 팁

  • 그림자 ON인 OmniLight는 6면 렌더링
  • DUAL_PARABOLOID 모드가 CUBE보다 빠름
  • 작은 range일수록 그림자 비용 감소
  • bake_mode = BAKE_STATIC이면 정적 조명으로 베이크 가능

func create_flashlight() -> SpotLight3D:
    var light = SpotLight3D.new()
    light.light_color = Color(0.95, 0.95, 1.0)  # 약간 차가운 흰색

SpotLight3D 주요 속성

  • spot_range - 빛이 도달하는 최대 거리
  • spot_angle - 원뿔의 반각 (0~90도)
  • spot_angle_attenuation - 가장자리 부드러움 (낮을수록 부드럽게)
활용 예시: 가로등(spot_angle=40, 아래 방향), 무대 조명(여러 색상의 SpotLight), 차량 전조등(2개의 SpotLight 병렬), 감시 카메라 빛(회전 애니메이션 추가)

조명 에너지와 색온도

밝기와 색상으로 분위기 연출

# 색온도를 Color로 변환하는 유틸리티
func kelvin_to_color(kelvin: float) -> Color:
    # 근사값으로 색온도 변환
    var temp = kelvin / 100.0
    var r: float
    var g: float
    var b: float
    if temp <= 66:
        r = 1.0
        g = clamp((99.47 * log(temp) - 161.12) / 255.0, 0.0, 1.0)
        b = clamp((138.52 * log(temp - 10) - 305.04) / 255.0, 0.0, 1.0) if temp > 10 else 0.0
    else:
        r = clamp((329.7 * pow(temp - 60, -0.133)) / 255.0, 0.0, 1.0)
        g = clamp((288.12 * pow(temp - 60, -0.0755)) / 255.0, 0.0, 1.0)
        b = 1.0
    return Color(r, g, b)
색온도 (K) 색상 실제 광원 분위기
1800K 주황 촛불, 일몰 따뜻함, 로맨틱
2700K 따뜻한 노랑 백열등 아늑함, 실내
4000K 중성 흰색 형광등 사무적, 일상
5500K 순백색 한낮 태양 자연스러움
7000K+ 차가운 파랑 흐린 하늘, 달빛 차가움, 신비
Tip: Godot 4의 Light3D에는 light_temperature 속성이 있어 직접 켈빈 값을 설정할 수 있습니다. light.light_color보다 물리적으로 더 정확합니다.

그림자 설정과 최적화

성능 품질과 성능의 균형 맞추기

# 프로젝트 설정에서 전역 그림자 품질
# rendering/lights_and_shadows/directional_shadow/size = 4096
# rendering/lights_and_shadows/directional_shadow/soft_shadow_filter_quality = 2
# rendering/lights_and_shadows/positional_shadow/soft_shadow_filter_quality = 2

# 런타임에서 그림자 품질 조절 (옵션 메뉴)
func set_shadow_quality(quality: int):
    var rd = RenderingServer
    match quality:
        0:  # 낮음
            rd.directional_shadow_atlas_set_size(1024, true)
            rd.positional_soft_shadow_filter_set_quality(
                rd.SHADOW_QUALITY_SOFT_VERY_LOW)
        1:  # 중간
            rd.directional_shadow_atlas_set_size(2048, true)
            rd.positional_soft_shadow_filter_set_quality(
                rd.SHADOW_QUALITY_SOFT_LOW)
        2:  # 높음
            rd.directional_shadow_atlas_set_size(4096, true)
            rd.positional_soft_shadow_filter_set_quality(
                rd.SHADOW_QUALITY_SOFT_MEDIUM)

그림자 아티팩트 해결

  • 줄무늬(Acne) - shadow_bias 증가 (0.05~0.2)
  • 피터 팬 - shadow_bias 감소, normal_bias 조절
  • 해상도 부족 - shadow atlas 크기 증가
  • 깜빡임 - shadow_normal_bias 증가
최적화 규칙: 1) 동시에 그림자를 켠 조명은 4~6개 이하로 제한. 2) 작은 장식 조명은 그림자 OFF. 3) distance_fade를 활용하여 멀리 있는 조명의 그림자를 자동 해제. 4) 모바일에서는 그림자 atlas를 1024~2048로 제한.

func setup_indoor():

    # 배경 (하늘 없음)
    env.background_mode = (
        Environment.BG_COLOR)

        0.01, 0.01, 0.02)

    # 환경광 (약하게)
    env.ambient_light_source = (
        Environment.AMBIENT_SOURCE_COLOR)
    env.ambient_light_color = Color(
        0.15, 0.12, 0.1)
    env.ambient_light_energy = 0.2

    # 후처리
    env.tonemap_mode = (
        Environment.TONE_MAP_ACES)
    env.tonemap_exposure = 1.2
    env.ssao_enabled = true
    env.ssao_intensity = 3.0
    env.glow_enabled = true
    env.glow_intensity = 0.6

    # 안개 없음 또는 약하게
    env.fog_enabled = false

func transition_to_indoor(duration: float):
