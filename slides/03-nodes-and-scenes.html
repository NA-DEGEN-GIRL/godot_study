노드(Node)란 무엇인가?

핵심 개념

노드(Node)는 Godot에서 게임을 구성하는 가장 작은 단위입니다.
모든 게임 오브젝트는 하나 이상의 노드로 구성됩니다.

  • 게임 내 모든 요소(캐릭터, 배경, UI, 사운드)는 노드
  • 노드는 이름, 속성, 콜백 함수를 가짐
  • 작은 노드를 조합하여 복잡한 오브젝트를 구성 (컴포지션 패턴)
  • 레고 블록처럼 조립하는 방식 = Godot의 설계 철학
비유: 노드 = 레고 블록 한 개, 씬 = 레고로 완성한 자동차나 집

노드 트리(Node Tree) 구조

# 트리 구조 예시 (플레이어)
Game (Node2D)            # 루트
 +-- Player (CharacterBody2D)
 |    +-- Sprite2D       # 외형
 |    +-- CollisionShape2D  # 충돌
 |    +-- AnimationPlayer   # 애니메이션
 |    +-- Camera2D       # 카메라
 +-- World (Node2D)
 |    +-- TileMap        # 지형
 |    +-- Enemies (Node2D)
 |         +-- Slime
 |         +-- Bat
 +-- UI (CanvasLayer)
      +-- HUD
      +-- PauseMenu

트리의 특징

  • 루트 노드: 트리의 최상단
  • 부모-자식 관계: 계층적 구조
  • 변환 상속: 위치/회전/크기가 부모 기준
  • 처리 순서: 위에서 아래로 순회
순환 참조 불가 - 자식이 부모가 될 수 없음

주요 노드 타입 계층

기본 클래스 용도 대표 하위 노드
Node 최상위 기본 클래스 (비시각적) Timer, AudioStreamPlayer, AnimationPlayer
Node2D 2D 게임 오브젝트 Sprite2D, CharacterBody2D, TileMap, Camera2D
Node3D 3D 게임 오브젝트 MeshInstance3D, CharacterBody3D, Camera3D
Control UI 요소 Button, Label, TextureRect, VBoxContainer
팁: 에디터 왼쪽 상단의 + 버튼으로 노드를 추가할 때, 검색창을 활용하면 빠르게 찾을 수 있습니다.

Node2D vs Control 비교

Node2D 계열

# Node2D의 주요 속성
position   # Vector2 위치
rotation   # float 회전 (라디안)
scale      # Vector2 크기
z_index    # int 렌더링 순서
visible    # bool 표시 여부
modulate   # Color 색상 변조

게임 오브젝트에 사용: 캐릭터, 적, 아이템, 배경 등

Control 계열

# Control의 주요 속성
anchor_left / anchor_top   # 앵커
offset_left / offset_top   # 오프셋
size        # Vector2 크기
size_flags_horizontal  # 플래그
custom_minimum_size    # 최소 크기
theme       # Theme 리소스

UI 요소에 사용: 버튼, 라벨, 메뉴, HUD 등

씬(Scene)이란?

정의

씬 = 노드 트리를 파일로 저장한 것 (.tscn 형식)
재사용 가능한 게임 오브젝트의 설계도(Template)입니다.

씬의 예시

  • player.tscn - 플레이어 캐릭터
  • enemy_slime.tscn - 슬라임 적
  • level_01.tscn - 1번 레벨
  • main_menu.tscn - 메인 메뉴
  • hud.tscn - HUD 인터페이스

씬의 특징

  • 씬 안에 다른 씬을 포함 가능
  • 독립적으로 테스트/실행 가능 (F6)
  • 하나의 씬 = 하나의 .tscn 파일
  • 메인 씬 지정: 프로젝트 설정에서

씬 저장과 불러오기

에디터에서 저장

Ctrl+S (씬 저장) / Ctrl+Shift+S (다른 이름으로 저장)

코드에서 불러오기

# 방법 1: preload - 컴파일 시점에 미리 로드 (권장)
var bullet_scene = preload("res://scenes/bullet.tscn")

# 방법 2: load - 런타임에 동적 로드
var level_path = "res://levels/level_" + str(level_num) + ".tscn"
var level_scene = load(level_path)

# 방법 3: ResourceLoader - 비동기 로드 (대용량)
ResourceLoader.load_threaded_request("res://scenes/boss.tscn")
# ... 나중에 결과 확인
var status = ResourceLoader.load_threaded_get_status("res://scenes/boss.tscn")
if status == ResourceLoader.THREAD_LOAD_LOADED:
    var boss_scene = ResourceLoader.load_threaded_get("res://scenes/boss.tscn")
preload vs load: 경로가 고정이면 preload, 동적이면 load 사용

인스턴싱(Instancing)

PackedScene.instantiate()

씬 파일(.tscn)을 실제 노드 트리로 복제하는 과정

# 1단계: 씬 리소스 로드
var enemy_scene: PackedScene = preload("res://scenes/enemy.tscn")

# 2단계: 인스턴스 생성 (아직 트리에 없음)
var enemy = enemy_scene.instantiate()

# 3단계: 속성 설정
enemy.position = Vector2(400, 300)
enemy.name = "Slime_01"

# 4단계: 트리에 추가 (이제 화면에 표시됨!)
add_child(enemy)
활용 예: 총알, 적, 아이템, 파티클 등 동일한 오브젝트를 반복 생성할 때 인스턴싱 사용
주의: instantiate()만으로는 화면에 표시되지 않음. 반드시 add_child() 필요!

노드 생명주기(Lifecycle)

_init()  -->  _enter_tree()  -->  _ready()  -->  _process() / _physics_process()  -->  _exit_tree()
 생성           트리 진입          준비 완료        매 프레임 반복 실행                     트리 이탈
        
extends Node2D

func _init():
    # 노드 객체 생성 시 (생성자)
    # 아직 트리에 추가되지 않은 상태
    print("1. 생성됨")

func _enter_tree():
    # 씬 트리에 추가될 때
    print("2. 트리 진입")

func _ready():
    # 자신과 모든 자식 노드가 트리에 들어온 후 (1회만)
    print("3. 준비 완료!")

func _process(delta: float):
    # 매 렌더링 프레임마다 (가변 FPS)
    pass

func _physics_process(delta: float):
    # 매 물리 프레임마다 (기본 60Hz 고정)
    pass

func _exit_tree():
    # 씬 트리에서 제거될 때
    print("5. 트리 이탈")

_ready() vs _process() 비교

_ready() - 초기화

func _ready():
    # 1회만 호출 (시작 시)
    # 용도: 초기화, 참조 획득

    # 노드 참조 저장
    sprite = $Sprite2D
    anim = $AnimationPlayer

    # 초기 상태 설정
    health = max_health
    position = start_pos

    # 시그널 연결
    $Button.pressed.connect(_on_btn)

_process(delta) - 매 프레임

func _process(delta: float):
    # 매 프레임 호출 (가변 FPS)
    # 용도: 입력, 이동, 애니메이션

    # delta = 이전 프레임과의 시간차
    # 60fps: delta ~ 0.0167
    # 30fps: delta ~ 0.0333

    # delta를 곱해야 프레임률 독립적!
    position.x += speed * delta

    # 입력 처리
    if Input.is_action_pressed("jump"):
        jump()
_physics_process(delta): 물리 연산(이동, 충돌)은 반드시 _physics_process에서! _process는 렌더링용.

노드 접근: get_node()와 $ 표기법

# get_node() - 경로로 노드 찾기
var sprite = get_node("Sprite2D")           # 직접 자식
var shape = get_node("Sprite2D/CollisionShape2D")  # 손자

# $ 표기법 - get_node의 단축키 (동일한 기능)
var sprite = $Sprite2D                      # 직접 자식
var shape = $Sprite2D/CollisionShape2D      # 손자

# 부모/형제 접근
var parent = get_parent()                   # 부모 노드
var sibling = get_parent().get_node("Sibling")  # 형제 노드
var root_node = get_tree().root             # 루트 노드

# % 고유 이름 (Unique Name) - Godot 4의 강력한 기능!
# 에디터에서 노드 우클릭 > "Access as Unique Name" 체크
var player = %Player    # 트리 어디서든 접근 가능
팁: %UniqueNode는 씬 내에서 고유 이름을 설정한 노드에 직접 접근합니다. 경로가 바뀌어도 안전합니다.
주의: $와 get_node()는 _ready() 이후에 사용! _init()에서는 아직 트리에 없어서 null 반환.

노드 추가/삭제 (동적 관리)

# === 노드 추가 ===
var label = Label.new()          # 코드로 노드 생성
label.text = "Hello Godot!"
add_child(label)                 # 자식으로 추가

# 특정 위치에 삽입
add_child(node)                  # 맨 뒤에 추가
add_child(node)                  # 기본
move_child(node, 0)              # 첫 번째 자식으로 이동

# === 노드 제거 ===
remove_child(label)              # 트리에서 분리 (메모리에 남아있음!)
label.queue_free()               # 프레임 끝에 안전하게 삭제 (권장)
label.free()                     # 즉시 삭제 (주의 필요)

# === 실전: 적 스폰 & 제거 ===
func spawn_enemy():
    var enemy = enemy_scene.instantiate()
    enemy.position = Vector2(randf_range(0, 800), 0)
    add_child(enemy)

func _on_enemy_died(enemy: Node):
    enemy.queue_free()           # 안전한 삭제
remove_child vs queue_free: remove_child()는 트리에서만 제거, 메모리 해제 안 됨! queue_free()가 메모리까지 정리.

부모-자식 관계의 특성

특성 설명 예시
변환 상속 부모 이동/회전/크기 변환이 자식에 전파 캐릭터(부모) 이동 시 무기(자식)도 이동
생명 연동 부모 삭제 시 자식도 모두 삭제 적 삭제 시 HP바, 그림자도 함께 사라짐
처리 순서 부모 _process가 자식보다 먼저 호출 게임 매니저가 먼저 상태 업데이트
owner 속성 씬 파일에 저장될 소유자 노드 에디터에서 볼 수 있는 노드 범위 결정 
# 부모-자식 관계 활용
func equip_weapon(weapon_scene: PackedScene):
    # 기존 무기 제거
    if $WeaponSlot.get_child_count() > 0:
        $WeaponSlot.get_child(0).queue_free()
    # 새 무기를 자식으로 추가 (부모 따라 이동)
    var weapon = weapon_scene.instantiate()
    $WeaponSlot.add_child(weapon)

씬 트리(SceneTree)

SceneTree의 역할

모든 활성 노드를 관리하고, 게임 루프를 구동하는 최상위 관리자

# SceneTree 접근
var tree = get_tree()

# 씬 전환
get_tree().change_scene_to_file("res://scenes/level_02.tscn")
get_tree().change_scene_to_packed(preload("res://scenes/level_02.tscn"))

# 게임 일시정지 / 해제
get_tree().paused = true   # 전체 일시정지
get_tree().paused = false  # 해제

# 게임 종료
get_tree().quit()

# 씬 리로드 (재시작)
get_tree().reload_current_scene()

# 그룹의 모든 노드에 함수 호출
get_tree().call_group("enemies", "take_damage", 10)

# 현재 씬의 루트 노드
var current_scene = get_tree().current_scene

노드 경로(NodePath)

# === 상대 경로 (현재 노드 기준) ===
$Sprite2D                        # 직접 자식
$Sprite2D/Light2D                # 자식의 자식
$"../Sibling"                    # 형제 (부모로 올라간 후)
$"../../Uncle/Cousin"            # 더 위로

# === 절대 경로 (루트부터) ===
get_node("/root/Main/Player")    # 루트에서 시작

# === NodePath 타입 활용 ===
@export var target_path: NodePath  # 에디터에서 드래그로 지정!

func _ready():
    var target = get_node(target_path)
    print(target.name)

# === 유용한 노드 탐색 메서드 ===
get_children()           # 모든 자식 배열
get_child_count()        # 자식 수
get_child(0)             # 인덱스로 자식 접근
find_child("Enemy*")     # 이름 패턴으로 검색
has_node("Sprite2D")     # 존재 여부 확인
팁: @export var target_path: NodePath를 사용하면, 인스펙터에서 노드를 드래그하여 경로를 지정할 수 있습니다.

실전: 플레이어 씬 구성

## player.tscn 트리 구조 ##

CharacterBody2D (Player)  # 루트
 +-- Sprite2D             # 캐릭터 그래픽
 +-- CollisionShape2D     # 충돌 영역
 +-- AnimationPlayer      # 애니메이션
 +-- RayCast2D            # 바닥 감지
 +-- Camera2D             # 카메라 추적
 +-- HitBox (Area2D)      # 공격 판정
 |    +-- CollisionShape2D
 +-- HurtBox (Area2D)     # 피격 판정
      +-- CollisionShape2D
# player.gd
extends CharacterBody2D

@export var speed := 200.0
@export var jump_force := -350.0
var gravity := 980.0

@onready var sprite = $Sprite2D
@onready var anim = $AnimationPlayer

func _physics_process(delta):
    # 중력 적용
    if not is_on_floor():
        velocity.y += gravity * delta

    # 점프
    if Input.is_action_just_pressed("jump"):
        if is_on_floor():
            velocity.y = jump_force

    # 좌우 이동
    var dir = Input.get_axis("left", "right")
    velocity.x = dir * speed

    # 스프라이트 방향
    if dir != 0:
        sprite.flip_h = dir < 0

    move_and_slide()
